# 00. エグゼクティブサマリー

> 最終更新: 2026-08-02（v6: チャンネル再編 — meme / trivia / f1 / heisei の4本立て）
> 本リポジトリは「個人SNS運用」の戦略・企画・運用のすべてを管理する。

## 結論

**最終ゴール: 積み上げた好感が、Phase 3で顔を出した本人に移ること。**

動画は**ずんだもん×四国めたんの掛け合いショート**。ネタは0から創作せず、
**実在のスレ・ニュース・事実から引用してオチから逆算する**（v5）。
4チャンネルを同じ型で回し、**どこが主戦場になるかを数字で決める**。

### 変更履歴（要点）

- **v5（2026-08-02）**: ネタを「LLM創作」から「掲示板引用・オチ逆算」へ（[04](./04_戦略.md) 2-2章）。
  本人評価「旧方式はつまらない」を受けた転換。テンポ（間詰め・効果音・パンチイン）も同時に刷新
- **v6（2026-08-02・本人決定）**: `girls`（モヤモヤ相談室）と `biz`（お金のホンネ）を**廃止**し、
  `meme` / `trivia`（実はそうだったんだ） / `f1`（F1ニュース） / `heisei`（平成懐かし系）の4本立てへ

### v3から何を変えたか（2026-07-30）

v3（ストック映像＋合成音声ナレーション）には**愛着の対象が構造的に存在しなかった**。
情報が役に立っても「便利なアカウント」止まりで、ファン化＝人への移行が起きない。

非顔出しで伸びている会話形式（ずんだもん掛け合い解説・Plott型キャラアニメ・猫ミーム）は
いずれも**キャラが愛着の受け皿**になっている。掛け合い形式は、YouTubeの
「単調な読み上げ＋スライドショー」という再利用コンテンツ判定の回避にも働く。

## 本人への橋

キャラのファンはキャラのファンで終わる。**好感を本人に移す橋**の設計は変わらないが、
⚠️ **v6で biz を廃止したため、「中の人（一人社長）」言及の主戦場が消えた**。
当面はプロフィール記載（「一人社長が作っています」）だけで橋を維持し、
**橋の再設計（どのチャンネルに・どう仕込むか）は主戦場の判定後に行う**（[#19](https://github.com/bashaka-sawabe/personal-sns-operation/issues/19)）。

```
Phase 1  プロフィールに中の人の存在を書く（言及の仕込み先は判定後に再設計）
Phase 2  本人が声・シルエットでキャラと共演し始める
Phase 3  顔出し共演 —「面白い・頼れる」がキャラから隣の本人に移る
```

橋が効いているかは**プロフィールアクセス率**で測る（計測実装済み）。

## いちばん重要な前提 — 2026年のプラットフォームはAI量産を抑制している

| PF | 内容 | 時期 |
|---|---|---|
| YouTube | 「**inauthentic content**」で収益化対象外。名指しされた例が **AI音声のナレーション＋生成映像で、人間の視点が足りないもの** | 2025-07-15 施行 |
| Instagram | 自分で作っていない内容が中心のアカウントを**おすすめから外す**。アグリゲータは到達 **-60〜80%**、オリジナル制作者は **+40〜60%** | 2026-04-30 |
| TikTok | AI生成のラベル表示が必須。**自己申告しなくても C2PA で検知**される | 2026年時点 |

3PFに共通する例外は「**そこに人間の視点が乗っているか**」。v6での人間の視点は
**実在のスレ・ニュース・事実を人が目視選別し、裏取りし、オチから逆算して編集すること**
（[04](./04_戦略.md) 2-2章）。trivia は一次ソースの裏取りを必須にし、
f1 は公式文書・データで事実を担保する。
キャラ掛け合いは見た目の器で、中身（実話と事実）が本体という構図は維持する。

## 素材規約の線引き（要点）

ずんだもん・四国めたんは借り物のキャラであり、規約に運用が縛られる（詳細 [08](./08_自動化.md)）:

- **音声（VOICEVOX）**: クレジット表記（`VOICEVOX:ずんだもん`）があれば個人・法人とも商用可
- **キャラ・立ち絵**: 個人クリエイターの動画広告収益は非商用範囲扱い。**法人利用・スポンサー案件は要契約**
- → **運用は個人名義で行う。Phase 2の種明かしで会社名と接続する前に、許諾の再確認が必須**

## 前提（確定・仮置き）

- **確定**: 最終ゴールは本人への好感移行／キャラはずんだもん×四国めたん（v4で「キャラは置かない」を撤回）／主戦場はチャンネル単位の数字で決める／顔出しは期限ではなく数字で判断
- **仮置き**: 稼働 週3〜7時間／2週間で判定（足りなければ延長する）
- 方針が変わったら [04_戦略.md](./04_戦略.md) を更新してコミットする
