# 00. エグゼクティブサマリー

> 最終更新: 2026-07-18（v2: 本人ヒアリングにより技巧・解説路線を破棄してピボット）／ 本リポジトリは「個人SNS運用」の戦略・企画・運用のすべてを管理する。

## 結論

**コンセプト: 「チケット外れたので、ピアノ弾きながらサカナクションの話をします」**

上手さでも音楽理論でもなく、**愛と悔しさと分析**で聴かせる、サカナクション特化のファンチャンネル。ピアノは「習ってたレベル」の等身大でBGM兼演出として弾く。飛び道具はAI分析、隠し味は「実は経営者」。

| レイヤー | 内容 |
|---|---|
| 最前面 | サカナクションが大好きなファン（今、ライブチケットが取れなくて悔しい当事者） |
| 演出 | 子供の頃習ってたレベルのピアノで、簡単に弾きながら喋る |
| 飛び道具 | AIでサカナクションをあれこれ分析（歌詞・セトリ予測・データ検証） |
| 隠し味 | 実は経営者・エンジニア（種明かしはPhase 2の演出資産に取っておく） |

### コンテンツピラー（2本＋横串）

| ピラー | 一言 | 根拠 |
|---|---|---|
| A. ファントーク×ピアノ | 弾きながらサカナクションを語る（落選の鬱憤・新曲リアクション・思い出） | 「演奏×トーク」は遠坂めぐ56万・ゆゆうた165万が実証済みの型。アーティスト特化版は無人（[02](./02_競合分析.md)） |
| B. AI×サカナクション研究 | 歌詞・セトリ・ストリーミングデータをAIで分析して遊ぶ | 音楽理論不要でエンジニアの強みが直撃。競合ゼロ（[02](./02_競合分析.md) 空白9） |
| 横串. 全公開 | フォロワー数・チケット戦績・練習過程をさらす | 共感と継続の仕掛け。X連携 |

**初手（7月中）: 「夜の踊り子」のリフを弾きながら、チケット落選の鬱憤を語る動画。** 2026年上半期最大の音楽ミーム（総再生11億回超）で新規ファンが急増中＝チケット倍率高騰に悔しがっている当事者が今いちばん多いタイミング。

## 根拠（詳細は各ドキュメント）

1. **競合**（[02](./02_競合分析.md)）: 技巧系・総合カバー型は大手飽和で頭打ち。伸びているのは「人格×型の反復」組。ポジショニングマップの「エンタメ・人格×専門特化」象限は遠坂めぐが型を実証済みで、**アーティスト特化は無人**
2. **トレンド**（[03](./03_トレンド調査.md)）: 夜の踊り子ミーム進行中＋サカナクションは8〜10月イベント密集（サマソニ→9/2シングル→9/8からアリーナツアー）。**ツアー期＝チケット難民の感情が最も動く期間**
3. **市場**（[01](./01_市場分析.md)）: 評価軸は完走率・保存・コメント。Xは権利上カバー動画NG（告知・AI企画の語り場に使う）。トーク型はコメント＝共感が資産になる

## 前提（確定・仮置き）

- **確定**: ピアノは子供の頃習ってたレベル（技巧・理論では戦わない）／最前面はファンであること／チケット落選の悔しさも当事者コンテンツにする
- 仮置き: ゴール＝ファン獲得主・本業シナジー副次／顔出し＝手元＋声で開始（トーク主体なので声が主役）／稼働＝週3〜7h
- 方針が変わったら [04_戦略.md](./04_戦略.md) を更新してコミットする

## Phase 1の数値目標（8〜10月）

投稿12本以上／ピラーA・Bのフォーマット別に完走率・保存・**コメント率**を比較／フォロワー1,000（ストレッチ3,000）／詳細: [06](./06_KPI・運用.md)

## 直近アクション（カンバンのCurrent）

2. アカウント3面開設＋X整備
3. 権利チェックフロー確立（J-WID/NexTone）
4. **初投稿:「夜の踊り子」を弾きながらチケット落選の鬱憤を語る**
5. 計測シート運用開始
