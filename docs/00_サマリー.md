# 00. エグゼクティブサマリー

> 最終更新: 2026-07-27（v3: 情報系ショート × AI生成パイプラインへピボット）
> 本リポジトリは「個人SNS運用」の戦略・企画・運用のすべてを管理する。

## 結論

**コンセプト: 「大人のメモ帳」— 知っておくと少しだけ得することを、1本30秒でメモしていく。**

お金・人間関係・世の中のしくみを扱う情報系ショート。
映像はAIで生成し、**ジャンルは決め打ちせず、3つを同じ型で回して数字で決める**。

| レイヤー | 内容 |
|---|---|
| 最前面 | 役に立つ情報（見る側にとって意味がある） |
| 手段 | AI生成映像＋ナレーション。1本あたり約68秒で作れる |
| 差別化 | **一人社長が実際に払っている金額・実際に踏んだ手順**（横流しでは書けない） |
| 到達点 | 「役に立つから見る」→「この人がやってるから見る」→ 顔と名前 |

### フェーズの順番（ここを間違えない）

```
Phase 1  有益情報で価値を出す        ← いま
Phase 2  情報から人へ移行する
Phase 3  顔と名前を出す
```

**個人の生活や好みを先に出しても受け入れられない。** 好かれていない段階で
「私はこういう人間です」を出すのは、見る側にとって何の意味もない。
先に価値を渡し、その積み上げの上でだけ人格に興味が移る。

## 3ジャンル2週間テスト

3ジャンル × 4本を同じ型で作り、数字で勝ちを決める（[data/themes.md](../data/themes.md)）。

| ジャンル | 内容 | 狙い | 弱点 |
|---|---|---|---|
| `money` | お金・経費・会社 | **信用移行が最大**。一人社長の一次情報が効く | 母数はやや小さい |
| `relationship` | 人間関係・印象・会話 | **母数最大**。日常で使える | 一次情報にしにくい |
| `trivia` | 雑学・由来 | **拡散力**。理解コストが低い | 人への信用移行が弱く、**AI量産と見分けがつかない**（下記） |

判定指標: **保存率・完走率・コメント率・プロフィールアクセス率**（[06](./06_KPI・運用.md)）。

## いちばん重要な前提 — 2026年のプラットフォームはAI量産を抑制している

| PF | 内容 | 時期 |
|---|---|---|
| YouTube | 「**inauthentic content**」で収益化対象外。名指しされた例が **AI音声のナレーション＋生成映像で、人間の視点が足りないもの** | 2025-07-15 施行 |
| Instagram | 自分で作っていない内容が中心のアカウントを**おすすめから外す**。アグリゲータは到達 **-60〜80%**、オリジナル制作者は **+40〜60%** | 2026-04-30 |
| TikTok | AI生成のラベル表示が必須。**自己申告しなくても C2PA で検知**され、累計13億本にラベルが付いている | 2026年時点 |

**このパイプラインが作るもの（生成背景＋合成音声＋字幕）は、YouTubeが名指しした形とほぼ同じ。**
にもかかわらずやる理由は、パイプラインを**勝ち筋そのものではなく、テストの回転数を上げる道具**として使うから。

3PFに共通する例外はひとつ、**「そこに人間の視点が乗っているか」**。
Instagramは明示的に「自分の見解・文脈・視点を重ねたものはオリジナル」と定義している。

→ **つまり、勝ち筋は最初から決まっている: 一人社長として実際に払った金額・実際に踏んだ手順を出すこと。**
`money` が構造的に有利なのはこのため。`trivia` は逆に最も危ない（横流しと区別がつかない）。

## 前提（確定・仮置き）

- **確定**: 有益情報が先／キャラは置かず映像とナレーションだけ／ジャンルは数字で決める／顔出しは期限ではなく数字で判断
- **仮置き**: 稼働 週3〜7時間／2週間で判定（足りなければ延長する）
- 方針が変わったら [04_戦略.md](./04_戦略.md) を更新してコミットする
