# 01. 市場分析 — 情報系ショート × SNS（日本・2026年7月）

> 調査日: 2026-07-27 ／ 一次ソース（総務省・プラットフォーム公式）優先。数値は出典と時点つき。
> 確認できなかったものは「不明」と明記する。

## TL;DR — 戦略的含意

1. **2026年最大の構造変化は「オリジナリティ規制」**。3PFすべてが、自分で作っていない内容・
   AIで量産した内容の到達を落としにきた。**情報系ショートは直撃する側**（4章）。
2. 例外はひとつ、**「人間の視点が乗っているか」**。Instagramは明示的に
   「自分の見解・文脈を重ねたものはオリジナル」と定義している → **一次情報が防具になる**。
3. リーチの土台は**YouTube**（全年代83.3%）。IG/TikTokがフロー（数日）なのに対し、
   YouTubeは**ストック**（検索経由で数ヶ月効く）。同じ12本でもYouTubeに置いた分だけが後に残る。
4. **TikTokは若者専用ではない**。利用者の平均年齢39.2歳。お金・人間関係の文脈は刺さる層。
5. 評価軸は3PF共通で**完走率・リピート・保存**。ショート60秒で完視聴率80%超が
   アルゴリズムの推薦ラインの目安。
6. 収益化は情報系でもバックエンド型が定石。**本プロジェクトの主目的はファン獲得**なので、
   収益設計はPhase 3に後置する。

## 2. アルゴリズム特性（2026年時点）

### 2-1. 共通する評価軸

| 順位 | 指標 | 意味 |
|---|---|---|
| 1 | 完走率・視聴維持率 | 最後まで見られたか。**再生数より優先される** |
| 2 | リピート（ループ再生） | 「もう一回見た」＝密度が高い |
| 3 | 保存 | 「後で使う」＝情報の価値。**情報系ショートの本丸** |
| 4 | コメント | 人格への関心。Phase 2への移行可能性を測れる |
| 5 | シェア | 拡散。Reelsで重視 |

- **60秒以内で完視聴率80%超**を出せると、アルゴリズムが積極的に推薦し始める
  （[ムビスケ 2026](https://www.muvisuke.com/column/547/) ／運用会社の経験則で公式数値ではない）
- YouTubeは2026年から**「Shorts → 長尺への誘導率」**を大きく評価するようになった。
  Shortsだけのチャンネルより、長尺も持つチャンネルが優遇される
  （[2ndBuzz](https://2nd-buzz.com/column/youtube-shorts-grow-guide/)）
  → **Phase 2で長尺（語り回）を持つ根拠**

### 2-2. 冒頭の設計

- TikTok: **冒頭3秒**で「何の動画か」を伝える。ジャンル一貫性がアカウント評価に影響
- YouTube Shorts: **冒頭1秒**でスワイプを止められるかが決定的
- 伸びない時の診断順序: ①冒頭1秒 → ②中盤離脱 → ③CTA不足 → ④初期配信数

出典: [アドネスラボ](https://addness.co.jp/media/youtube-short-algorithms/) / [mazikamazika](https://mazikamazika.com/column/tiktok-algorithm-2025/)

### 2-3. Instagram Reels

- 最重要シグナル: **視聴時間 → シェア（DM送信）→ いいね**。2025年以降「保存」重視から「シェア」重視へシフト
- Meta公式推奨: 3分以内・**オリジナルコンテンツ**・他SNSの透かし入りは露出減・ミュート/低解像度は減点

出典: [コムニコ（Meta公式発表ベース）](https://www.comnico.jp/we-love-social/ig-algorithm)

### 2-4. 投稿時間帯の目安

| PF | ピーク帯 |
|---|---|
| Instagram | 20〜22時（朝7〜8・昼12〜13も有効） |
| TikTok | 19〜23時 |
| YouTube | 17〜18時公開 → 20〜22時のおすすめを狙う |

出典: [SNSCHOOL](https://snsschool.net/column/sns-marketing/posting-time)

## 3. フローとストック — YouTubeだけ性質が違う

| PF | 寿命 | 役割 |
|---|---|---|
| TikTok | 数日 | **発見エンジン**。0フォロワーでも段階配信でバズり得る |
| Instagram Reels | 数日 | **主戦場**。30〜40代に届く |
| Threads | 数時間〜数日 | **テスト場**。テキストで反応を見てから動画化できる |
| **YouTube Shorts** | **数ヶ月** | **ストック**。検索の長尾で効き続ける。収益化条件も最も明確 |

「経費で落ちるもの」のような**検索需要のあるテーマは、YouTubeに置いた分だけが3ヶ月後も効く**。
テスト期でも必ず4面すべてに出す理由がこれ。

## 4. 2026年のオリジナリティ規制（最重要・本プロジェクトに直撃）

### 4-1. 何が起きたか

| PF | 内容 | 時期 |
|---|---|---|
| **YouTube** | 収益化ポリシーの「repetitious content」を「**inauthentic content**」に改称。**大量生産・反復的・独自の洞察を欠く**内容を収益化対象外に。名指しされた例: テキスト生成動画のみで構成された動画／使い回し映像／**ストック画像に自動音声を乗せたもの**／低労力AI生成の大量投稿 | 2025-07-15 施行 |
| **Instagram** | **自分で作っていない内容が中心のアカウントを、フォロワー以外へのおすすめから外す**。Reelsだけでなく写真・カルーセルを含む全形式へ拡大。視覚的に70%以上似ている投稿は再投稿として配信減。30日で10本以上の再投稿はおすすめ完全除外 | 2026-04-30 |
| **TikTok** | AI生成コンテンツのラベル表示が必須。**自己申告しなくても C2PA Content Credentials・電子透かし・検知モデルで判定**され、累計13億本にラベルが付いている。適切にラベルを付けたAI生成は収益化対象のまま。台本生成など**テキスト工程のAI利用はラベル不要** | 2026年時点 |

出典: [Social Media Today](https://www.socialmediatoday.com/news/youtube-clarifies-monetization-update-inauthentic-repeated-content/752892/) / [YouTube Help](https://support.google.com/youtube/answer/1311392?hl=en) / [Tubefilter 2026-04-30](https://www.tubefilter.com/2026/04/30/instagram-removes-algorithm-recommendations-repost-content-aggregator/) / [PetaPixel](https://petapixel.com/2026/04/30/new-instagram-policies-target-reposted-content/) / [Storrito](https://storrito.com/resources/tiktoks-2026-ai-labeling-rules-and-what-they-signal-for-platform-governance/)

### 4-2. 実測されている影響（Instagram・2026年4月の変更後）

| | 到達の変化 |
|---|---|
| アグリゲータ型アカウント | **-60〜80%** |
| オリジナル制作者 | **+40〜60%** |

出典: [Instagram Original Content Rule 2026](https://gotmenow.com/2026/05/12/instagram-original-content-rule-2026/)（二次情報。Meta公式の数値ではない）

### 4-3. 例外 — 何が「オリジナル」とみなされるか

3PFに共通する線引きは **「人間の視点・文脈が乗っているか」**。

- YouTube: 「AIツールの利用は歓迎する。ただし**最終的な動画に人間が加えた固有の価値**が必要」
- Instagram: ユーモア・社会的な論評・文化的文脈・**自分の見解**を、独自のテキスト・編集・
  ナレーションで重ねたものは**オリジナルとみなす**

### 4-4. 本プロジェクトへの結論（誤魔化さずに書く）

**このリポジトリのパイプラインが作るもの（生成背景 ＋ 合成音声 ＋ 焼き込み字幕）は、
YouTubeが名指しした形とほぼ一致する。** これを認めた上で、次の3点で線を引く。

1. **パイプラインは勝ち筋ではなく、テストの回転数を上げる道具**。
   1本68秒で作れるからジャンル判定が2週間で終わる。勝ち筋が決まったら中身を差し替える
2. **一次情報を必ず乗せる。** 一人社長として実際に払った金額・実際に踏んだ手順は、
   横流しでは書けないし、AIにも書けない。これが唯一の防具
3. **合成音声を使う間はTikTokでラベルを付ける。** 隠すと検知され、配信が絞られる。
   Phase 2で本人の声に差し替えることは、品質向上であると同時に**規制回避策そのもの**

→ ジャンル別のリスク: `money`（一次情報にできる＝**最も安全**）> `relationship` > `trivia`（**最も危険**。横流しと区別がつかない）

## 6. 情報の正確性 — 情報系における「権利処理」に相当するもの

演奏系における音楽権利にあたるリスクが、情報系では**内容の誤り**。
特に `money` は、数字を間違えると1本が滑るだけでなく**チャンネルの信用ごと飛ぶ**。

| 領域 | 気をつけること |
|---|---|
| 税務・社会保険 | 税率・上限額・要件は年度で変わる。**「2026年時点」と明示する**。断定を避け、条件付きで言う |
| 資格の線引き | 個別の税務相談・法律相談は**業として行うと資格が要る**。一般的な情報提供に留め、「詳細は税理士へ」と添える |
| 出典 | 一次ソース（国税庁・日本年金機構・厚労省）を確認してから書く |
| 一次情報 | 「自分の会社ではこうだった」は強い。ただし**一般化しない**（「うちの場合は」と限定する） |

投稿前チェックリストは [05_コンテンツ企画.md](./05_コンテンツ企画.md) 5章。
