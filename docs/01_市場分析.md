# 01. 市場分析 — ピアノ演奏コンテンツ × SNS（日本・2026年7月）

> 調査日: 2026-07-18 ／ 一次ソース（総務省・プラットフォーム公式・業界団体）優先。数値はすべて出典と時点つき。確認できなかったものは「不明」と明記。

## TL;DR — 戦略的含意

1. **リーチの土台はYouTube**。全年代の83.3%が利用し、30〜40代でも9割超。ピアノ演奏の主要視聴層（大人）まで届く唯一の全年代基盤。
2. **TikTokは「若者専用」ではない**。利用者は3人に1人・平均年齢39.2歳まで上昇。新規発見エンジンとして年齢を理由に外す根拠はもうない。
3. 3プラットフォーム共通で評価軸は**完走率・リピート・保存/シェア**。冒頭1〜3秒が生命線 → 演奏動画は「サビ・聴かせどころ・意外性」から始めるのが原則。
4. **Instagram Reelsは音源経由の発見導線が構造的に演奏系有利**（Meta公式が音源付き投稿を推奨。同じ曲を探す人に露出する）。
5. **Xには演奏動画を投稿しない**（JASRAC/NexTone包括契約の対象外＝カバー投稿は権利処理が必要）。Xは告知・テキスト・データ発信専用と割り切る。→ 運用ルールに直結
6. 広告収益は演奏系では小さい（ショート0.05〜0.1円/再生、音楽利用分の配分あり）。収益化はレッスン・楽譜・案件・ファン課金の**バックエンド構造**が定石。本プロジェクトの主目的はファン獲得なので、収益設計はPhase 3に後置。
7. マクロは追い風: 縦型動画広告は**前年比+55.9%**で急拡大、クリエイターエコノミーは年平均15.5%成長。生成AI普及で「人間の生演奏」の相対価値が上がる局面。

## 2. アルゴリズム特性と「伸ばす」セオリー（2025〜2026年時点）

### 2-1. YouTube Shorts

- 評価指標: 視聴完了率・**スワイプせず視聴した割合**・いいね・コメント・シェア。シェアと保存の影響度が大きい
- 運用会社の経験則の目安: スワイプ率60%以上で合格／70%以上でバズ圏内、視聴維持率70〜80%合格／90%超でバズ圏内（公式数値ではない）
- **冒頭1秒**でスワイプを止められるかが決定的。伸びない時の診断順序: ①冒頭1秒 → ②中盤離脱 → ③CTA不足 → ④初期配信数
- ショートで認知 → 長尺・ライブで回収する導線が定石（長尺の方が収益単価が高い）

出典: [アドネスラボ（2026-07-18更新）](https://addness.co.jp/media/youtube-short-algorithms/) / [デジタルレクリム 2026年版](https://www.digital-reclame.co.jp/blog/youtube-monetization-strategy-2026/)

### 2-2. TikTok

- 段階的テスト配信（少数表示→反応が良ければ拡大）のため**フォロワー0でも1本目からバズが起こり得る**
- 指標の優先順位: ①完視聴率・視聴維持率 ②繰り返し視聴 ③保存 ④コメント ⑤シェア。「視聴維持×リピート×保存」が最重要
- **冒頭3秒**で「何の動画か」を伝える。ジャンル一貫性がアカウント評価に影響。ハッシュタグは3〜8個

出典: [mazikamazika（2025-11-15）](https://mazikamazika.com/column/tiktok-algorithm-2025/) / [マーケドリブン](https://pamxy.co.jp/marke-driven/sns-marketing/tiktok-algorithm/)

### 2-3. Instagram Reels

- 最重要シグナル: **視聴時間 → シェア（DM送信）→ いいね**。2025年以降「保存」重視から「シェア」重視へシフト
- Meta公式推奨: 3分以内・オリジナルコンテンツ・**音源付き推奨**（トレンド音源経由のおすすめ流入）・他SNSの透かし入りは露出減・ミュート/低解像度は減点
- 演奏動画は「音源そのもの」がコンテンツ → 音源ページ経由の発見導線が構造的に有利

出典: [コムニコ（2026-01-30、Meta公式発表ベース）](https://www.comnico.jp/we-love-social/ig-algorithm)

### 2-5. 演奏系コンテンツへの適用原則

演奏系特化の公開統計は存在しない（不明）ため、上記仕様からの導出ルール:

1. **サビ・最高難度の聴かせどころ・意外性を冒頭0〜3秒に置く**（イントロから弾き始めない）
2. トレンド曲は**早さが正義**（TikTok/Reelsの音源導線・検索需要に乗る）
3. ショート15〜30秒はループ設計（終わり→冒頭が繋がるとリピート再生が伸びる）
4. 同一ジャンルの一貫性を保つ（アカウント評価）
5. 旧譜・カタログ曲リバイバルも狙い目（TikTokグローバル年間1位が1962年の曲になる時代。→ 5章）

## 4. 権利処理ルール（最重要・運用に直結）

### 4-1. できること／できないこと

| ✅ OK | ❌ NG／要注意 |
|---|---|
| JASRAC/NexTone管理曲を**自分の演奏**でカバーし、包括契約済みサービス（YouTube/TikTok/Instagram等）へ投稿 | **市販CD・配信音源・カラオケ音源（DAM/JOYSOUND等）の流用** → 原盤権侵害。個人では実質許諾困難 |
| 上記動画で広告収益を得る（YTはContent ID経由の権利者分配あり） | **Xへの演奏動画投稿** → 包括契約なし。個別許諾が必要 |
| 包括対象のライブ配信サービスでの演奏配信（TikTok LIVE等） | **企業案件動画での楽曲使用** → 包括対象外。「広告目的複製」の個別手続きが必要 |
| 自作カラオケ音源・許諾済み配布音源の使用 | JASRAC/NexToneどちらも管理していない曲（ゲーム音楽の一部・自主管理曲）→ 権利者へ直接許諾 |
| | 市販楽譜をそのまま画面に映す・配布する → 複製権の別問題 |

### 4-2. 包括契約の現状（2026年時点・一次ソース）

- **JASRAC**: [UGCサービス一覧（2026-04-08更新）](https://www.jasrac.or.jp/information/topics/20/ugc.html) — YouTube・TikTok・Instagram・ニコニコ・Twitch等 約50サービス。**Xは非掲載**
- **NexTone**: [許諾済みUGC一覧PDF（2026-06-25更新）](https://www.nex-tone.co.jp/files/ugc.pdf) — YouTube・TikTok（LIVE含む）・Instagram等 約40サービス。**Xは非掲載**。Meta系は「投稿機能に限る」注記あり

### 4-3. 投稿前の確認フロー（毎回実施・チェックリスト化）

1. [J-WID（JASRAC作品DB）](https://www2.jasrac.or.jp/eJwid/)で曲を検索 → 「配信」欄の管理状況を確認
2. 無ければ [NexTone作品検索](https://search.nex-tone.co.jp/) を確認
3. どちらにも無い場合は権利者に直接確認（ゲームBGM等はメーカーの二次創作ガイドラインを確認）
4. 編曲譜を販売する場合はPiascore等の申請代行を利用（大幅な編曲は著作者本人の許諾が別途必要）

出典: [JASRAC 動画投稿サービスでの音楽利用](https://www.jasrac.or.jp/users/internet/ugc/) / [サンレコ「歌ってみたの著作権」](https://www.snrec.jp/entry/special/utattemita_copyright)（2022記事・原則は現在も同様）

## 5. 市場規模・マクロトレンド

- **国内クリエイターエコノミー市場: 2兆894億円（2024年実績）**、2021年比で年平均約15.5%成長。潜在市場14.6兆円（[クリエイターエコノミー協会×MURC 2025-12-10](https://prtimes.jp/main/html/rd/p/000000026.000082387.html)）
- **国内動画広告市場: 2025年 8,855億円（前年比+22.2%）**。うち**縦型ショート動画広告は2,049億円（前年比+55.9%）**、2029年に5,648億円へ拡大予測（[サイバーエージェント 2026-03-09](https://www.cyberagent.co.jp/news/detail/id=33050)）
- **国内レコード市場: 2025年 3,988億円**（うちストリーミング1,377億円。[日本レコード協会 2026-03-04](https://www.riaj.or.jp/news/press/94d112e4-697a-4990-9f80-a721d1f5a921/)）
- **カタログ曲リバイバル**: TikTokグローバル年間1位（2025）は1962年のConnie Francis「Pretty Little Baby」（使用2,840万回超）。旧譜・クラシックがショート発で再燃する構造は、クラシック素養のある演奏者への追い風（[TikTok Year in Music 2025](https://newsroom.tiktok.com/tiktokyear-in-music-2025?lang=ja-JP)）
- **ショート発ヒットの公式化**: MUSIC AWARDS JAPANに「最優秀バイラル楽曲賞」新設（2025-04）。バズ→音楽業界評価の回路が確立（[TikTok Newsroom](https://newsroom.tiktok.com/ja-JP/music-awards-japan-nominees)）
- **生成AIの普及**で創作の新規参入が増える一方、「人間の実演・生演奏」の差別化価値は相対上昇（[Musicman 2025-12](https://www.musicman.co.jp/business/704944)）
