# 02. 競合分析 — 情報系ショートの構造

> 調査日: 2026-07-27 ／ 前提: [01_市場分析.md](./01_市場分析.md)（特に4章のオリジナリティ規制）

## 0. このドキュメントの限界を先に書く

**アカウント単位の一次データ（登録者数・保存率）は取れていない。**
情報系ショートのジャンル別ベンチマークは公開統計が存在せず（[01](./01_市場分析.md) 8章）、
個別アカウントの数値は推測でしか書けない。推測を根拠のように扱うと判断を誤る。

そこで本ドキュメントは**アカウント名の羅列ではなく、発信者の「型」の分析**に絞る。
型が分かれば、自分がどの型で、誰と比較されるかが決まる。
**アカウント単位の実データは2週間テストで自分の数字として取る**（[06](./06_KPI・運用.md)）。

---

## 1. 情報系ショートの発信者は4類型に分かれる

| 型 | 中身 | 強み | 2026年の弱み |
|---|---|---|---|
| **A. 専門家型** | 税理士・弁護士・医師など有資格者が本業の知識を出す | 資格そのものが信用。指名検索が付く | 本業が忙しく本数が出ない。言えることに制約がある |
| **B. 当事者型** | 経営者・投資家・現場の人が**自分が実際にやったこと**を出す | **一次情報。横流しできない**。数字に生々しさがある | 一般化できない。母数が本人の経験に限られる |
| **C. アグリゲータ型** | 調べた内容をまとめ直す。編集は上手い | 本数が出る。ジャンルを選ばない | **2026年4月以降、到達 -60〜80%**（[01](./01_市場分析.md) 4-2） |
| **D. AI量産型** | 生成映像＋合成音声＋自動台本を大量投下 | コストがほぼゼロ | **YouTubeが名指しで収益化対象外**。TikTokは自動検知でラベル付与 |

### 構造の変化 — 2026年に何が反転したか

2025年まではC（アグリゲータ）が最も効率が良かった。**2026年にそれが反転した。**

```
〜2025年   本数 × 編集のうまさ  → C が勝つ
2026年〜   一次情報 × 人格      → A と B が勝ち、C と D は配信が絞られる
```

情報そのものの希少性はAIによって消えた。**残った希少性は「誰が言っているか」**。

## 2. ポジショニング

```
                  一次情報あり（2026年に強い）
                        ↑
                        │
        A 専門家型      │      B 当事者型  ★ここを狙う
      （資格で信用）    │   （経験で信用）
                        │
  資格・肩書き ─────────┼───────── 人格・生き様
                        │
        C アグリゲータ  │      D AI量産型
      （編集で勝負）    │   （量で勝負）
                        │
                        ↓
                  一次情報なし（2026年に弱い）
```

★ **B（当事者型）の右上に入る。**

- 資格は無い（税理士ではない）ので A には入れない
- C・D は2026年の規制で構造的に不利。**パイプラインの見た目はDだが、中身をBにする**
- **一人社長として実際に払っている社会保険料・実際に通した経費**は、
  資格が無くても出せる一次情報

### 自分が持っているもの・持っていないもの

| 持っている | 持っていない |
|---|---|
| 一人社長として会社を回している実体験 | 税理士・社労士などの資格 |
| エンジニアとしての実装力（AI・自動化） | 顔出しの実績・既存フォロワー |
| 数字を扱うことへの抵抗の無さ | 話芸・タレント性の実証 |

「資格が無い」ことは B の型では弱点にならない。**B は「制度」ではなく「自分の実例」を語る型**だから。
ただし一般化した断定をすると A の領域に踏み込んで事故る（[01](./01_市場分析.md) 6章）。

## 3. ジャンルごとの競合状況（構造推定）

| ジャンル | 想定される競合の型 | 混雑度 | 自分の勝ち目 |
|---|---|---|---|
| `money` | A（税理士・FP）が多い。B は**少ない** | 中 | **高**。「税理士が言う一般論」と「一人社長が実際に払った額」は別物。B の席が空いている |
| `relationship` | C（アグリゲータ）が支配的。心理学の引用が多い | **高** | 中。一次情報にしにくいが、「経営者として人を採る／断る」文脈なら B にできる |
| `trivia` | C・D が支配的 | **極高** | **低**。一次情報が原理的に乗らない |

> ⚠️ **`trivia` はテストで数字が出ても、そのまま採用しない可能性がある。**
> 拡散はするが、① 人格への移行が起きない ② C・Dと区別がつかず2026年の規制側に立つ。
> 判定のときにこの但し書きを必ず思い出すこと（[06](./06_KPI・運用.md) 2章）。
>
> それでもテストに入れているのは、**「拡散だけならどれくらい出るのか」の上限を知るため**。
> 比較対象が無いと、`money` の数字が良いのか悪いのか判断できない。

## 4. 勝ちパターン（型に共通する要素）

情報系ショートで伸びているものに共通するのは次の3つ。

1. **1本1論点。** 30秒で言い切れることしか扱わない。「〇選」は分割する
2. **冒頭で結論の一部を見せる。** 「経費で落ちるのに9割が申告してないもの」のように、
   タイトルの時点で「知らないかも」と思わせる
3. **反復可能な型を持つ。** 毎回フォーマットが同じだと、
   視聴者が「この形式は最後まで見る価値がある」と学習する

### 2026年に追加された4つ目

4. **人間の視点が乗っていること。** これが無いと、そもそも配信されない（[01](./01_市場分析.md) 4章）

## 5. 空白（狙える隙間）

| # | 空白 | 根拠 |
|---|---|---|
| 1 | **一人社長のリアルな金額** | 税理士は「制度」を語るが「自分がいくら払ったか」は語らない。当事者しか出せない |
| 2 | **経営者視点の人間関係** | 「断り方」「採用で見ているところ」は、心理学の引用より具体的で、かつ一次情報にできる |
| 3 | **AIで作っていることを隠さない情報系** | 大半は隠す。**作り方ごと見せる**のはエンジニアの強みが直撃し、かつ誠実 |
| 4 | **数字を全部公開する運用** | 0→1,000の全公開は共感と継続の仕掛けになる |

3 と 4 は Phase 2 で効く。「AIで作っている」と言った上で中身に一次情報が乗っていれば、
それは規制が求めている姿そのものであり、**弱点の告白ではなく差別化になる**。

---

## 6. 比較しないこと（炎上ガードレール）

- 他クリエイターの数字を引き合いに出して批評しない
- 「税理士は教えてくれない」のような**専門家を貶める煽り**を使わない（Aの型と敵対する必要がない）
- 公開するデータは**自分の数値のみ**

詳細は [06_KPI・運用.md](./06_KPI・運用.md) 7章。
