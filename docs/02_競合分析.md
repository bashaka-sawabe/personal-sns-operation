## 0. 旧方針「アカウント名の羅列はしない」を撤回した

旧版は冒頭でこう宣言していた:

> アカウント単位の一次データは取れていない。（略）
> そこで本ドキュメントは**アカウント名の羅列ではなく、発信者の「型」の分析**に絞る。

**これが失敗だった。** 実在チャンネルを見ないまま設計した結果、
効果音は2種類・テンポも演出も**4チャンネルすべて同じ値**という動画ができた
（本人評価「効果音・テンポ・ワードチョイスが単調で面白くない」2026-08-02）。

型の分析は「誰と比較されるか」までしか教えてくれない。
**「何秒で切るか」「どこで音を鳴らすか」「冒頭で何と言うか」は実物を見ないと分からない。**
一次データは取れないのではなく、**取りに行っていなかった**（登録者数・再生数・尺・
テロップ枚数は、動画を実際に取得すれば全部測れる）。

以下は4ジャンルの実在チャンネルを実測した結果。ジャンルごとに勝ち方が違う。

### 1-2. `showa` のベンチマーク（実測・2026-08-09・[#152](https://github.com/bashaka-sawabe/personal-sns-operation/issues/152)）

`showa` の尺の目標（55〜59秒）は**トリビアの沼（単一ナレーションの雑学解説）から借りた値**で、
寸劇形式に妥当かを検証していなかった。実測してレンジを決め直す。

**まず前提**: 「昭和専門 × 寸劇 × 登録者1万人以上」のチャンネルは**存在しなかった**。
見つかった2つは、いずれもコント／サラリーマン系チャンネルの**看板シリーズとして昭和をやっている**。
合成音声（VOICEVOX等）で昭和×寸劇のチャンネルは1万人以上に1つも無い。

| | ボチリスト | わせだや |
|---|---|---|
| URL | [@botirist_](https://www.youtube.com/@botirist_) | [@わせだや](https://www.youtube.com/@わせだや) |
| 登録者 | **176万** | 14.5万 |
| 昭和シリーズ | 「昭和すぎて〇〇するニキ」 | 「昭和じゃないと通らない提案」「【時代別】〇〇の違い」 |
| その実績 | 看板回で **628〜1,441万回** | 看板回で **103〜347万回** |
| **尺（ショート全体の中央値）** | **67秒** | **45秒** |
| **再生上位1/3の尺** | **64秒** | **43秒** |
| 再生下位1/3の尺 | 74秒 | 46秒 |
| 話者 | 2人（昭和すぎる本人＋常識人） | 2人（昭和の上司＋若手） |
| テロップ | 話者ごとに色分け（白／緑）・常時 | 常時。**パワーワードだけ赤/金で特大** |
| フック | **0秒から会話の途中**。状況説明はしない | 同じ |
| 声 | 実写・肉声 | 実写・肉声 |

（尺は YouTube Data API で機械実測。ボチリスト58本・わせだや79本。
話者数・テロップ・フックは各1本のコマ検証なので n=1。効果音の有無は未確認）

**読み取れること**:

1. **寸劇は26.7秒（meme）より長くてよい。実測レンジは43〜67秒。**
   借り物の55〜59秒はレンジ内ではあったが、根拠が無いままだった
2. **両チャンネルとも、同じチャンネル内で短い方が伸びている**
   （ボチリスト 64秒 vs 74秒／わせだや 43秒 vs 46秒）。長くする方向に伸びしろは無い
3. **0秒から会話の途中に放り込み、状況説明を映像でしない。**
   状況説明は**タイトル帯（0秒から最後まで出しっぱなし）に丸投げ**している。
   この設計はこちらの実装と同じなので、変えるべきはタイトル帯の文言の情報量の方
4. 176万人のチャンネルが64秒でやっている以上、**尺の短さ自体が勝ち筋ではない**。
   ただし伸ばす理由も無いので、レンジの短い側に置く

**決めたこと**: `showa` の尺は **43〜55秒**（`max_chars` 364 → 330）。
自チャンネルの実測は中央値52.9秒・話速403字/分で、330字なら約49秒に収まる。

#### 読み取れること → `jiji` が採るべき型

1. **ショート×時事キャラは無人の谷**。10万人の前例が無いまま出すのは賭けだが、
   部品は全部10万人チャンネルで実証済み: 表情差分立ち絵・掛け合い・前置きゼロフック・オチ先出し。
   **前例のない組み合わせを、実証済みの部品だけで組む**と整理する
2. 尺は**60秒近辺**から始める（速報63本の実測は60秒固定で、尺と再生の相関なし）。
   このジャンルの本命が長尺（13〜16分）なのは明白なので、ショートの型が当たったら
   長尺化は Phase 2 の長尺導入（[07](./07_ロードマップ.md)）に乗せる
3. **フックは0秒から寸劇の中盤 or オチの先出し**。状況説明はタイトル帯に丸投げ（1-2と同じ結論）
4. **キャラは3人所属・画面同時2人まで**。表情差分は必須（[#306](https://github.com/bashaka-sawabe/personal-sns-operation/issues/306) の4表情はベンチ実証済みの演出）
5. **政治は「制度・構造をキャラの人格で面白くする」側**に寄せ、特定政党・特定個人への
   支持/攻撃をしない（[#305](https://github.com/bashaka-sawabe/personal-sns-operation/issues/305) のpersona線引きの実測根拠。大手が存在しない上に7章の炎上ガードレールにも反する）
6. 差別化の軸はスレ引用ではなく**キャラの人格の衝突**（銀行員vs弁護士vs諜報員）。
   人格なしの読み上げ最大手が3.2万で休止している通り、読み上げでは登録理由を作れない。
   ネタ選定はロンロン採点に乗せ、台本は立場の衝突で書く（[#310](https://github.com/bashaka-sawabe/personal-sns-operation/issues/310)）

## 2. `meme` — 2ch色を捨てたチャンネルが勝っている

**最重要の発見。** [ロンロンの天秤](https://www.youtube.com/@ロンロンの天秤)（51.2万・ショート専業2,192本）は
**掲示板の記号を全部捨てている**。直近48本のタイトルを機械集計した結果:

| | ロンロン（51.2万） | なんJ民と秘密の部屋（11.9万） |
|---|---|---|
| `www` を含む | **0%** | 81% |
| `【悲報】` を含む | **0%** | 52% |
| タイトル平均文字数 | **28字** | 53字 |

レス番号・安価・ID・名前欄も**一切画面に出さない**。代わりに:

- 背景は**2chと無関係の飯テロ/ASMR映像を全画面**で流し、0.4秒ごとにカット
- 中央に**丸い話者アイコン**（話者が変わるとアイコンも変わる）＋その下に白1行。
  アイコンの中身は**実写風の人物顔写真**（色付きリングの丸抜き。2026-08-05 サムネイル実測・
  [#154](https://github.com/bashaka-sawabe/personal-sns-operation/issues/154)）。
  **VOICEVOXキャラの絵は画面に出していない**。スレ民を「どこかにいる実在っぽい人」として見せている
- **オチのパワーワードだけ特大の青/黄文字**で画面幅いっぱい
- タイトルは **【4〜6字の名詞句の煽り】**（ルールの盲点／妙な説得力／斜め上の祝福／類語の勝利…）

対して従来型の「なんJ民と秘密の部屋」（11.9万・5ch使用許諾済）は
**直近ショートが2,000〜3,000回**まで落ちている（過去作は137万回）。

> **ネタの選定基準そのものが変わる**: ロンロンは
> 「**コメントで復唱できるパワーワードが1個作れるか**」でスレを選んでいる。
> 実例では駅アナウンスの空耳を「シャマルピー」と提示し、コメント欄が
> 「シャマルピー草」「「「「「ｼｬﾏﾙﾋﾟｰ」」」」」で埋まっている。

### 2-2. ロンロンの脚本構造（実測・2026-08-06）

直近ショート8本（38万〜220万回）の字幕を書き起こして展開を分析した。
一次データは [data/ronron_transcripts.md](../data/ronron_transcripts.md)。
「キチガイっぽいのに知性を感じる」の正体は、**感情ではなく言葉とロジックのレベルで
裏切りを起こし、当事者だけが大真面目**という分裂にある。8本すべてで型は共通、
差が出るのはネタの強度だけだった。

**台本プロンプトに転記する型（8本の共通項）**:

1. **0秒＝リアクション先出し**。状況説明から始めない。「厨房『なんやこの注文』」のように
   *何かが既に起きた後* から開幕し、何が起きたかは伏せる
2. **説明は会話内の質問への回答として後出し**する（「何頼んだ？」方式）。ナレーションで説明しない
3. **ボケの当事者は最後まで大真面目**。周囲（レス・面接官・店長）が常識人としてツッコむ。
   本人が笑ったり自覚したりした瞬間に壊れる
4. **裏切りは言葉とロジックで起こす**。実測での内訳:
   - 同音異義の押し通し（座右の銘→左右の目→信条→身長、と2段で再演する）
   - 多義語の取り違えを指示どおり全力実行（つまみを出す→客をつまみ出す）
   - ルールの穴を突く制度ハック（「き」から始まる食べ物→自分で作って命名すればよい）
   - 語彙の接合ミスの敬語（「すっかり真夏のこの頃」「心を込めてごめんなさい」）
   - 言語ネタの収集大喜利（頭痛が痛い系の実例列挙）
5. **オチは2種類だけ**: (a) 感情への異常に精密な名づけ・例え（「野良猫を撫でた後
   ついて帰られる時みたいな申し訳なさ」）、(b) 冷静な一般化で被害者ぶる（「日本語も難しいよな」）。
   どちらも**パワーワード＝コメントで復唱される行**になる
6. **パワーワードの位置は数値で決まっている**: 30秒級なら24〜30秒（オチ）、
   15秒級なら0秒（お題自体がパワーワード）。中間には置かない
7. **効果音を声で発声する**（ルルルル・ガチャ・ポチ・どすん）。素人劇の作法が人間味になる
8. **異常に具体的なディテールを1個入れる**（「保留BGMのサビ直前にガチャ」「登録者16人」
   「右1.5左0.7」）。数字か固有の状況で、嘘のリアリティを支える
9. **尺は2種類**: 会話劇は30〜35秒、大喜利列挙は15秒。中途半端な20〜25秒が最も少ない
10. **スラングは台詞の中**（ワイ・ンゴ・関西弁・にゃ等のキャラ語尾）。
    タイトルには出さない（www 0%・【悲報】0%は1章の実測どおり）

論理的に振る舞う**から知性に見える。壊す前提を2個以上にすると、ただの出鱈目になる。

### 2-4. ロンロンの音まわり（実測・2026-08-11・[#250](https://github.com/bashaka-sawabe/personal-sns-operation/issues/250)）

2-2章は**字幕の書き起こしベース**で、脚本構造は実測済みだが音の設計が記録されていなかった。
直近ショート5本（計90.5秒・68万〜153万回）を ffmpeg で測った。

| | ロンロン（実測5本） | うち（`meme-025`〜`027`） |
|---|---|---|
| **BGM** | **常時鳴っている**。5本すべてで -50dB以下の無音が**0箇所** | 素材は選ばれているが、**途中で完全な無音が0.15〜0.35秒**（3本すべて） |

| **カット** | 0.50秒に1回（0.35〜0.92） | 4.3〜5.1秒に1回（＝シーンの切れ目だけ） |

| 台詞が無い区間 | 全体の11%・**最長0.49秒** | 最長0.93秒 |

**結論1: BGMは敷き続ける。ただし今は敷けていない。**
ロンロンは最後まで音を切らさず、声とBGMのあいだに **31〜37dB** の落差を作っている。

**500msの復帰時間より台詞の間のほうが短い**（最長0.49秒）ため、
一度沈んだBGMが戻る前に次の台詞が来る。結果、BGMは鳴りっぱなしのつもりで
**実質ずっと沈んだまま**になり、動画の途中に完全な無音ができている。
→ ダッキングの調整は別Issue（本Issueは調査）。

**結論2: カット音は不要**。「0.4秒カット＋効果音」ではなく、
**カットは無音で切っている**（対照実験で確認）。
効果音を使わない現方針（[#203](https://github.com/bashaka-sawabe/personal-sns-operation/issues/203)）と矛盾しない。

> ⚠️ **0.5秒カットは実装しない。** 背景のハードカットは本人指示で全廃済み

> [#203](https://github.com/bashaka-sawabe/personal-sns-operation/issues/203)・「チカチカして見るのが疲れる」）。

## 2-3. `meme` のテロップ間隔を実測で詰めた（2026-08-11・[#247](https://github.com/bashaka-sawabe/personal-sns-operation/issues/247)）

ベンチマークは **1.1秒/テロップ**。尺（実測30.6秒 / ベンチ26.7秒）は合っていたので、
問題は**行数**だった。

> **測るときの注意**: 「秒/行」と「秒/テロップ」は別物。字幕は台詞1行ではなく
> **フレーズ単位**で出す（句読点で割る。4-3）ので、1行が2〜3枚になる。
> 直近4本の実測は **2.35秒/行 = 1.65秒/枚** で、比較すべきは後者。

| | 実装前 | 実装後（新規3本） | ベンチマーク |
|---|---|---|---|
| 尺 | 28.8秒 | **28.3秒** | 26.7秒 |
| セリフ行数 | 12.2行 | **20.0行** | — |
| テロップ枚数 | 17.5枚 | **23.7枚** | — |
| **テロップ間隔** | 1.65秒/枚 | **1.20秒/枚** | **1.1秒/枚** |
| 秒/行 | 2.35秒 | **1.42秒** | — |
| 話速 | 470字/分 | **401字/分** | 300〜400字/分 |

決めた値は `lines_total` **20〜24**（`9〜13` から）と `max_chars` **195**（`230` から）。
**尺を動かさずにテンポだけ上げるには、字数を減らして行数を増やすしかない**
（同じ28秒でも12行なら2.35秒/行、20行なら1.42秒/行）。

話速が 470 → 401字/分 に下がったのは speed をいじったからではなく、
**1行を短く割るとフレーズの前後の無音が増える**ため。字/秒は 7.65 → 6.64 になった。

**行数はスキーマでは縛れない。** structured output は配列の `minItems` に 0 と 1 しか
許さず、それ以外は 400 が返る（実測）。合計行数は `form_issues()` が数えて差し戻す。

## 4. `heisei` — 掛け合いではなく「◯◯選」の高速リスト

**現在の自分の設計（1本1ネタの掛け合い）は、このジャンルでは実績のない型。**

[1989年生まれの放課後](https://www.youtube.com/@1989houkago)（1.12万・176本）が
**登録者の20倍**の再生を叩き出している:

| タイトル | 再生 |
|---|---|
| 1989年生まれ**位**が懐かしい飲み物６５選 | **21万** |
| 【平成レトロ】1989年生まれが懐かしい玩具100選 | 13万 |
| 【平成レトロ】1989年生まれチョイス懐かしいもの100選【小学校編】 | 9.3万 |

- **2.5秒/ネタ**。2〜4分に65〜100個を投げつける
- **「位（くらい）」の一文字**が決定打。「1989年生まれ**位**が」で1985〜1995年生まれ全員を取り込む。
  断定形の回より伸びている
- 画面は商品写真を白いカードに載せ、**カードが左→右に流れて画面に溜まる**グリッド蓄積

対して**1本1ネタの情報提示型は185本出して1,000〜3,000回**（昭和・おぼえていますか 4,770人）。
**例外は身体性のある1ネタ**で、よもぎ（9,120人）は「探す→見つける→開ける」の
実体験ショートで5〜11万回を出している。

### コメントが伸びる仕掛けは2つだけ

実際のトップコメントを分析すると、コメントの正体は**「年齢の名乗り」と「リストの穴埋め」**:

- 「**36歳男**…平成に戻りたい…」（♥138）／「**60才女性ですが**どれも懐かしい…」
- 「フキゲンとかこの動画見るまで死ぬまで忘れてた自信あるわwwww」（＝リストに無いものを補完）

**「◯◯選」は全部入りきらないからコメントが来る。** 世代明示は年齢を名乗る動機を作る。
概要欄で質問を3つに割る（「夢中になったアイドル」「よく見ていた番組」「忘れられない出来事」）と、
コメントがその構造どおりに返ってくる。

### 権利面（クリーンで一番安い型）

**THEヤバイ昭和**（2.46万）の概要欄がそのまま答え:
`photoAC / illustAC / freepik / O-DAN` ＋ `DOVA-SYNDROME` ＋ `VOICEVOX:四国めたん`。
**ブラウン管テレビの枠画像の中に素材写真をはめる**だけで「昭和」が成立している。
当時の物は1つも要らない。

逆に**やってはいけないのは「著作権法32条の引用です」型**。当時のCM・番組映像を並べて
概要欄で32条を主張しているチャンネルが複数あるが、32条は主従関係・必然性・明瞭区別が要件で、
映像を主コンテンツとして並べる使い方は通常満たさない。
