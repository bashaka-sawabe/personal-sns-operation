# 03. トレンド調査 — ショート動画の作法とAI規制の流れ（2026年7月）

> 調査日: 2026-07-27 ／ 前提: [01_市場分析.md](./01_市場分析.md)
> 数値の一部は運用会社の集計・経験則であり公式発表ではない。その旨は都度明記する。

## TL;DR

1. **2026年の最大の潮流はAI量産の選別**。3PFが同じ方向を向いた（2章）。
   情報系ショートは直撃する側なので、**トレンドではなく前提として扱う**。
2. ショートの**平均視聴時間が45秒 → 58秒に伸びた**。短ければ良い時代は終わり、
   **情報密度の高い長めのShorts**が評価される。
3. 編集の標準が上がった。**ジャンプカット（無音の全カット）が標準仕様**、
   **2〜3秒に1回は視覚的な変化**を入れないと維持率が保てない。
4. YouTubeは **Shorts → 長尺への誘導率**を大きく評価するようになった。
   Shorts単独チャンネルより長尺も持つチャンネルが優遇される。
5. ショートは「1本の大ヒット」より**継続投稿**で決まる。だから**作り続けられる仕組み**が
   コンテンツの質と同じくらい効く（＝パイプラインを作った理由）。

## 1. ショート動画の作法の変化（2025 → 2026）

| | 〜2025年 | 2026年 |
|---|---|---|
| 尺 | 短いほど良い（15〜30秒） | **情報密度が高ければ長くてよい**（平均視聴時間 45秒→58秒） |
| 編集 | 適度なカット | **無音部分の全カット（ジャンプカット）が標準** |
| 画変化 | 冒頭が勝負 | **2〜3秒に1回**の視覚変化が必須 |
| 勝ち方 | 1本のバズ | **継続投稿**の積み上げ |
| チャンネル設計 | Shorts単独で成立 | **Shorts → 長尺の導線**が評価される |

出典: [2ndBuzz（1億本のデータ分析）](https://2nd-buzz.com/column/youtube-shorts-grow-guide/) /
[ムビスケ](https://www.muvisuke.com/column/547/) /
[ショート動画トレンド2026](https://0120.co.jp/blog/video-43/)
（いずれも運用会社・分析ツール提供者による集計。プラットフォーム公式の数値ではない）

### 本プロジェクトへの反映

| 変化 | パイプラインでどう対応するか | 状態 |
|---|---|---|
| 情報密度の高い長め | 5シーン構成（フック＋本編3点＋締め）。尺は音声に合わせる | **実装済** |
| 2〜3秒に1回の視覚変化 | シーンごとにストック映像を切り替え＋**フレーズ同期字幕**（数秒ごとに字幕が入れ替わる） | **実装済**（[09](./09_パイプライン.md) 4-3） |
| ジャンプカット | 合成音声なので無音がそもそも無い | 構造上クリア |
| 継続投稿 | 1本数分で作れる（素材取得込み） | **実装済** |
| Shorts → 長尺 | Phase 2で長尺（語り回）を持つ | 未着手（[07](./07_ロードマップ.md)） |

> 補足（2026-07-29）: 当初はグラデーション背景＋静的字幕で「変化が緩い」弱点を抱えたまま
> 進めようとしていたが、**フィード水準を下回る画ではテスト自体が成立しない**ため、
> ストック映像＋フレーズ同期字幕に引き上げた（[09](./09_パイプライン.md) 4-1〜4-3）。
> それでも完走率が伸びない場合は、次にフレーズ割りの粒度と冒頭1秒を疑う。

## 2. AI生成コンテンツをめぐる規制の流れ（これが最大のトレンド）

```
2025-07  YouTube  「inauthentic content」施行。AI量産を収益化対象外へ
2026-04  Instagram 非オリジナル中心のアカウントをおすすめから除外（全形式へ拡大）
2026     TikTok    AI生成ラベル必須。C2PA等で自己申告なしでも検知（累計13億本）
```

詳細と出典は [01_市場分析.md](./01_市場分析.md) 4章。

### 読み方

これは「AIを使うな」ではなく **「AIで薄めたものを大量に流すな」**。
3PFとも、AIツールの利用そのものは明示的に許容している。

線引きは一貫して **「人間の視点・文脈が乗っているか」**。
→ 本プロジェクトの結論は [01](./01_市場分析.md) 4-4 と [04_戦略.md](./04_戦略.md) 2章。

### 逆張りの機会

規制が効くほど、**「自分の実体験を出せる人」の相対価値は上がる**。
参入は激増したが、一次情報を持つ人の数は増えていない。
2026年は、**当事者型（[02](./02_競合分析.md) 1章のB）にとって追い風**。

## 3. テーマの旬 — 情報系における「季節」

音楽と違ってミームに乗る必要はないが、**情報系には検索需要の季節がある**。

| 時期 | 需要が立つテーマ | ジャンル |
|---|---|---|
| 1〜3月 | 確定申告・医療費控除・ふるさと納税の締め | `money` |
| 3〜4月 | 新年度・異動・新しい人間関係・4月始まりの由来 | `relationship` / `trivia` |
| 6〜7月 | 賞与・社会保険の算定基礎届・年末調整の前倒し話 | `money` |
| 9〜10月 | 年末調整の準備・インボイス関連 | `money` |
| 11〜12月 | 年末調整・ふるさと納税の駆け込み・忘年会の断り方 | `money` / `relationship` |

**いまは7月末** = `money` は「社会保険の算定基礎届」「賞与から引かれる額」の旬。
[data/themes.md](../data/themes.md) の「一人社長の社会保険料のリアルな金額」はここに乗っている。

> 季節ものは**検索の長尾が効くYouTubeでこそ価値がある**（[01](./01_市場分析.md) 3章）。
> 1〜3月の確定申告テーマは、**前年の秋までに置いておくと翌年の申告期に効く**。

## 4. 定点観測（週次レビューで見る）

週次レビュー（[06](./06_KPI・運用.md) 4章）で以下を確認し、テーマ候補を [data/themes.md](../data/themes.md) に足す。

| 見るもの | どこで | 何を拾うか |
|---|---|---|
| 自分の投稿の検索流入キーワード | YouTube Analytics | **実際に検索されている言葉**。テーマの言い換えに使う |
| コメント欄の質問 | 4面すべて | 「それ知りたい」がそのまま次のテーマになる |
| 制度変更 | 国税庁・日本年金機構の新着 | `money` は**制度が変わると過去動画が誤情報になる**。要確認 |
| PFのポリシー更新 | 各PFの公式ブログ | 2章の流れは続く。[01](./01_市場分析.md) 4章を更新する |

**制度変更の監視は義務**。古い税率のまま置いてある動画は、資産ではなく負債になる。
