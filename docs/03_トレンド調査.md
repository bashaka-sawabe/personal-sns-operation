# 03. トレンド調査 — バズ曲・ミーム曲とサカナクション動向（2026年7月）

> 調査日: 2026-07-18。一次ソース（TikTok公式Newsroom・Billboard JAPAN・オリコン等）を優先。「カバー相性」列は出典ではなく本調査による評価（クラシック経験のあるピアノ弾きがショート/YouTubeで演奏カバーする前提）。

## TL;DR

1. **最優先は サカナクション「夜の踊り子」（2012年曲）**。2026年上半期最大の音楽ミーム（総再生11億回超・TikTok上半期トレンド大賞受賞）で、**原曲の核が反復ピアノリフ** — ピアノカバーがそのまま「ミーム音源」として使われ得る稀有なタイミング。ミーム進行中の今が投稿適期。
2. サカナクションは**2026年8〜10月にイベント密集**（8月サマソニ → 9/2シングル「怪獣/いらない」→ 9/8〜10/4アリーナツアー）。**8〜9月を「サカナクション月間」にする時流的根拠**がある。シングルには公式「いらない Piano ver.」収録予定 = ピアノ親和性を公式が実証。
3. 2026年の旬: 好きすぎて滅！（M!LK）・Partner（有華）・ハチミツ（aiko）・SUMMER SONG（YUI・毎夏リバイバル）・lulu.・AIZO。
4. 検索需要が安定した2025年組: IRIS OUT（米津・技巧見せ枠）・Golden（ボーカル無しでも成立する希少なバズ曲）・怪獣・ライラック・APT.。
5. 「間奏を演奏する」ミーム（マカロニえんぴつ「ルート16」）が発生中 = **演奏系アカウントへの追い風**。

### 3-2. 「夜の踊り子」ミームの経緯（2026年の教科書的事例）

インドネシアの伝統ボートレース（パチュ・ジャルール）で踊る少年の映像 → 韓国ユーザーが2012年の「夜の踊り子」を合成 → 2026年4月に日本へ逆輸入され「ボート少年ダンス再現」がテンプレ化（M!LK・乃木坂46など参加）→ 4/25に山口一郎本人が配信で踊り公認 → 5月にオリコン週間ST 7位（14年目で初TOP10）・総再生11億回超 → TikTok上半期トレンド大賞2026インパクト・ソング部門受賞。

出典: [citra経緯まとめ 2026-05](https://citracitrus.com/music-sakanaction2/719/) / [オリコン 2026-05](https://www.oricon.co.jp/news/2454275/full/) / [TikTok Newsroom 2026-06-30](https://newsroom.tiktok.com/tiktok-h1-trend-awards-2026?lang=ja-JP)

### 3-3. カバー需要の優先順（本調査の提案）

1. **夜の踊り子** — 原曲の主役が反復ピアノリフ。ピアノ版がミーム音源として「使われる」可能性がある唯一のタイミング（今）
2. **怪獣** — MAJ 8冠 → 9/2シングル → 9月ツアーで秋まで話題継続。単発カバーは飽和しているので**語り・企画つき**で出す（[02_競合分析.md](./02_競合分析.md) 5章）
3. **新宝島** — 公式公認ミーム・検索が枯れない定番。差別化必須
4. **いらない** — 公式「Piano ver.」が9/2に出る = 発売週に合わせた企画が有効
5. 代表曲メドレー（ミュージック/アイデンティティ/忘れられないの 等）— ツアー期のセトリ予習需要（推測）

## 4. 演奏カバーが伸びやすい定番ジャンル（直近1年）

- **アニメ主題歌（最重要）**: ストリートピアノ人気曲ランキング（[STPIA](https://stpia.jp/song/)・2025年末時点）はTOP10の過半がアニソン・ネット発。直近の新規ヒット: 鬼滅・無限城編W主題歌（2025-07〜、第二章に向け継続）／IRIS OUT／lulu.（フリーレン）／AIZO（呪術）／クスシキ（薬屋2期）／Plazma・BOW AND ARROW（米津・2025年間10位）／革命道中（ダンダダン2期）
- **ゲーム・ネット発**: マリオ「Jump Up, Super Star!」Remixが2026年前半の世界的トレンド。千本桜（ボカロ）・RUSH E（ネットミーム超絶技巧曲）はストピ定番演目
- **クラシック・インスト**: STPIAランキングに「ラ・カンパネラ」6位・「戦場のメリークリスマス」10位・「情熱大陸」5位 → **「ガチクラシックをショートで聴かせる」枠は確立済み**。クラシック経験の直接活用先
- **シティポップ**: 海外人気は継続だが定着期。2025〜26年に日本のショートで新規大規模ミーム化した例は**未確認**。海外向けタグ運用の常設レパートリーとしては有効
