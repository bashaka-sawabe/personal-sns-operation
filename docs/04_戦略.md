# 04. 戦略 — フレームワーク分析と基本方針

> 根拠: [01_市場分析](./01_市場分析.md)・[02_競合分析](./02_競合分析.md)・[03_トレンド調査](./03_トレンド調査.md)
> v3（2026-07-27）: 情報系ショート × AI生成パイプラインへ全面ピボット。
> **v4（2026-07-30）: ペルソナ別3チャンネル × キャラ掛け合いへピボット。**
> 理由: v3のナレ＋ストック映像には愛着の対象が構造的に存在せず、ファン化しない
> （＝最終ゴールへの橋が架からない）ため。「キャラは置かない」を撤回した。

## 0. 前提条件

| 項目 | 内容 | 確度 |
|---|---|---|
| 発信者 | 敦史（BASHAKA代表取締役・エンジニア） | 確定 |
| **最終ゴール** | **積み上げた好感が、Phase 3で顔を出した本人に移ること** | **確定（本人・v4）** |
| フェーズの順番 | **①キャラで価値と愛着を作る → ②本人が共演で合流 → ③顔と名前**。個人の生活や好みを先に出さない | **確定（本人）** |
| 見せ方 | **ずんだもん×四国めたんの掛け合い**（v4で「キャラは置かない」を撤回） | **確定（本人・v4）** |
| チャンネル | **ペルソナから逆算した3チャンネル**（[05](./05_コンテンツ企画.md) 1章）を同じ型で回し、主戦場を数字で決める | **確定（本人・v4）** |
| 顔出し | **期限では決めない。数字で判断する** | **確定（本人）** |
| 制作 | AI生成（映像・音声・台本）で自動化する | **確定（本人）** |
| 稼働 | 週3〜7時間 | 仮置き |

## 1. 3C分析

### Customer（誰が見るか）

| | 内容 |
|---|---|
| 中心 | 30〜50代。会社員・フリーランス・小規模事業者 |
| 状態 | 「あとで調べよう」で終わっていることが山ほどある。調べる時間はない |
| 動機 | 損したくない・恥をかきたくない・少しだけ得したい |
| 行動 | **保存する**（後で使う）。すぐには行動しない |

この層はYouTube 83〜92%、Instagram 52〜70%、TikTok 25〜40%（[01](./01_市場分析.md) 1章）。
**TikTokの平均年齢は39.2歳**なので、「若者向けだから経費の話は刺さらない」は誤り。

### Competitor（誰と比べられるか）

4類型（[02](./02_競合分析.md) 1章）。要点は**2026年にC・Dが構造的に不利になった**こと。

| 型 | 2026年の状態 |
|---|---|
| A 専門家型（税理士等） | 強い。ただし本数が出ない |
| **B 当事者型** | **強い。かつ席が空いている** |
| C アグリゲータ型 | 到達 -60〜80% |
| D AI量産型 | 収益化対象外・自動検知 |

### Company（自分は何を持っているか）

| 資産 | 使い道 |
|---|---|
| **一人社長として会社を回している実体験** | `money` の一次情報。**これが唯一かつ最大の武器** |
| エンジニアとしての実装力 | パイプラインの自作。回転数で他を上回る |
| 数字への抵抗の無さ | 全公開運用（Phase 2の素材） |
| 顔・実名を出す用意がある | Phase 3の切り札。**先に使い切らない** |

**持っていないもの**: 資格・既存フォロワー・話芸の実証。ここで戦わない。

## 2. 戦略の核 — 見た目はD、中身はB

いちばん重要な設計判断。v4でもこの構図は変えない。

```
見た目（作り方）   キャラ掛け合い＋合成音声＋自動台本   ← 類型D（規制される側）
中身（情報）       一人社長が実際に払った金額          ← 類型B（規制されない側）
```

v4で加わった役割: **キャラは愛着の受け皿**でもある。掛け合いは「単調な読み上げ＋
スライドショー」という再利用コンテンツ判定の回避に働き、同時にファン化の器になる。
ただし**キャラのファンはキャラのファンで終わる**ので、本人への橋（7章）が必須。

**この2つを同時に成立させる。** どちらか片方だと負ける。

| もし | 何が起きるか |
|---|---|
| 中身もDだったら（横流し情報をAIで量産） | YouTubeで収益化対象外、Instagramでおすすめ除外。**規制の直撃** |
| 作り方もBだったら（全部手作業） | 1本1.5〜2時間。週2本が限界で、**2週間でジャンル判定ができない** |

パイプラインは**勝ち筋ではなく、テストの回転数を上げる道具**（[01](./01_市場分析.md) 4-4）。
1本68秒で作れるから、3ジャンル×4本を2週間で回せる。手作業なら3ヶ月かかる。

> **だから、当てるべきは「型」であって「本数」ではない。**
> 当たった型が決まったら、生成の中身を差し替えて質を上げる（[07](./07_ロードマップ.md) Phase 2）。

## 3. STP

### Segmentation / Targeting

| セグメント | 狙うか | 理由 |
|---|---|---|
| 制度をちゃんと学びたい人 | ✗ | 税理士のチャンネルに勝てない |
| **「知らないと損する」を拾いたい人** | **◎** | 30秒で価値が渡る。保存される |
| エンタメとして雑学を消費する人 | △ | 拡散はするが人格に移行しない（[02](./02_競合分析.md) 3章） |
| 起業・独立を考えている人 | ○ | Phase 2以降の本命。`money` から自然に繋がる |

### Positioning

> **「税理士が制度を教えてくれる。ここでは、一人社長が実際にいくら払ったかを見せる。」**

比較対象は税理士ではなく、**「同じ立場の先輩がいたら聞きたかったこと」**。
専門家を貶める煽り（「税理士は教えてくれない」）は使わない（[02](./02_競合分析.md) 6章）。

## 4. チャンネル設計 — ペルソナから逆算した3つを同じ型で回す

v3の「ジャンル」を、v4では**ペルソナ別チャンネル**に引き上げた。2025〜26年のYouTubeは
チャンネル全体の一貫性を評価するため、性質の違う内容を1チャンネルに混ぜない。

| ch | ペルソナ | 仮説 | 弱点 |
|---|---|---|---|
| `girls` | ミサキ（26・会社員） | **主戦場候補**。最終ゴールの相手層を直接集める。保存されやすい | 一次情報にしにくい |
| `biz` | ケンタ（34・独立2年目） | **信用の土台**。一次情報が乗る唯一のチャンネル。種明かしで最も動く | 母数はやや小さい |
| `meme` | ユウ（24・ミーム好き） | **拡散力とキャラ人気**のテスト。コメント率が最も出る | 本人への信用移行が最も遠い |

**3つで固定する。** 増やすと1チャンネルあたりの本数が減って判定できない。
④サトシ（普通の人）は専用チャンネルを持たない（[05](./05_コンテンツ企画.md) 1章）。

他PF（IG・TikTok・Threads）は勝ちチャンネル確定まで**1アカウント運用**。

### なぜ「まずテストする」なのか

`girls` が主戦場だという読み（最終ゴールからの逆算）はある。だが**読みと実測は別物**。

- ベンチマークが公開されていない（[01](./01_市場分析.md) 8章）
- 掛け合いの型が、どのペルソナで機能するかは未知
- 「刺さるかどうか」は、ペルソナではなく**書き方**で決まる可能性がある

外から取れないなら自分で取る。**それが2週間テストの意味**。

> ただし判定時は数字だけで決めない。`meme` が勝った場合、それは**キャラの勝ち**であって
> 本人への移行からは最も遠い。最終ゴール（本人への好感移行）に照らして解釈すること
> （[06](./06_KPI・運用.md) 2章の但し書きと同じ構図）。

## 5. プラットフォーム戦略

| PF | 役割 | 投稿 |
|---|---|---|
| **YouTube Shorts** | **主面**。3チャンネルに分けて出す。検索の長尾・収益化条件が最も明確 | 自動（実装済・**3チャンネル対応は要改修**） |
| Instagram Reels | 20〜40代女性に最も届く（`girls` の本命面） | 未実装・当面1アカウント |
| TikTok | **発見エンジン**。0フォロワーでも当たる | サードパーティ経由・当面1アカウント |
| Threads | **テスト場**。テキストで反応を見てから動画化できる | 未実装・当面1アカウント |
| X | 告知・進捗。運用の主軸にはしない | 手動 |

**YouTubeのみチャンネルを分け、他PFは1アカウントに全部出す。**
チャンネル分割の判定精度と、稼働（週3〜7時間）・アカウント管理コストのバランスを取る。
勝ちチャンネル確定後、そのペルソナ専用のIG/TikTokアカウントを立てる。

### Threadsの使い方（安く外す）

動画を作る前に、テーマをテキストでThreadsに出して反応を見る。
**外れを、作る前に知れる。** 1本68秒とはいえ、当たらないテーマに使う理由はない。

## 6. SWOT

| | 追い風 | 向かい風 |
|---|---|---|
| **内部** | **S**: 一次情報を持っている／実装力／数字への抵抗が無い／顔出しの用意がある | **W**: 資格が無い／フォロワー0／話芸が未実証／**2〜3秒に1回の画変化が弱い**（[03](./03_トレンド調査.md) 1章） |
| **外部** | **O**: 2026年の規制で当事者型が相対的に有利／情報系は検索の長尾が効く／縦型広告市場が+55.9% | **T**: **パイプラインの見た目が規制対象と一致**／制度変更で過去動画が誤情報化／情報系は参入が激増 |

### 重要な向かい風への手当て

| 脅威 | 手当て |
|---|---|
| 見た目が規制対象と一致 | 中身を一次情報にする（2章）＋TikTokでAIラベルを付ける＋Phase 2で本人の声へ |
| 制度変更で誤情報化 | 週次レビューで制度更新を確認（[03](./03_トレンド調査.md) 4章）。古い動画は非公開にする |
| 画変化が弱い | 完走率が伸びなければ最初にここを疑う（[03](./03_トレンド調査.md) 1章） |

## 7. 本人への移行設計（Phase 1 → 2 → 3 の橋）

**キャラのファンはキャラのファンで終わる。** ずんだもんが100万回再生されても、
モテるのはずんだもんである。最終ゴール（本人への好感移行）には橋の設計が必須で、
**ずんだもんは本人に変換できない**（声も人格も借り物）ため、橋は「共演」方式にする。

| 仕込み | 具体 | いつから |
|---|---|---|
| **キャラに「中の人」を語らせる** | `biz`:「このチャンネルの中の人（一人社長）は、実際〇〇円だったのだ」。1本1回 | **Phase 1の最初から** |
| 数字を中の人のものにする | 一般論ではなく実額（一次情報スロット） | **Phase 1の最初から** |
| プロフィールに中の人の存在を書く | 「一人社長が作っています」 | **Phase 1の最初から** |
| **本人が共演し始める** | 声・シルエットでキャラと掛け合い。キャラは本人をいじる相棒役に回る | Phase 2 |
| 全公開 | フォロワー数・数字の推移を出す | Phase 2 |
| 種明かし | 「実は経営者・エンジニア」 | Phase 2。**先に使い切らない** |
| 顔・実名で共演 | キャラに積もった「面白い・頼れる」が隣の本人に移る | Phase 3（[07](./07_ロードマップ.md)） |

**橋の効きはプロフィールアクセス率で測る**（「中の人って誰？」の数）。
コメント率はキャラへの愛着、プロフィールアクセス率は本人への関心。**両方見る。**

## 8. 本業との距離

- 会社名・サービス名を先に出さない。**Phase 2の種明かしまで取っておく**
- **素材規約上の制約もある**: ずんだもん等のキャラの法人利用・スポンサー接続は要契約
  （[08](./08_自動化.md)）。運用は個人名義で行い、**会社名と接続する前に許諾を再確認する**
- 個別の税務相談・法律相談はしない（資格の線引き。[01](./01_市場分析.md) 6章）
- 実名公開は**取り消せない**。Phase 3で本業との接続込みで決める
