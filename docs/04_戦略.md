## 1. 3C分析

### Customer（市場・顧客）
- 第一顧客は**サカナクションファンダム**。「夜の踊り子」ミーム（総再生11億回超・上半期トレンド大賞）で新規ファンが急増中＝**ファン人口の拡大期**（03参照）
- 同時に、2025年復帰ツアー全公演即日SOLD OUT→2026アリーナツアーへと**チケット倍率が高騰し、「行けない悔しさ」を抱えた人の母数が過去最大**。この感情は9/8のツアー開幕に向けてさらに高まる
- アルゴリズム面は3PF共通で完走率・保存・コメント（01参照）。トーク型コンテンツは**コメント＝共感の連鎖**が伸びの燃料になる

### Competitor（競合）
- 「演奏×トーク」フォーマットは実証済み: 遠坂めぐ（弾きながら関係ない話・56.1万人）、ゆゆうた（演奏×雑談配信・165万人）
- ただし両者とも「何でも弾く総合型」。**特定アーティスト特化のファントークチャンネル（演奏つき）は不在**（02の空白2）
- 技巧系・解説系・総合カバー型は大手飽和＋素養前提 → **戦わない**（ここで勝負しない判断は競合データ的にも合理的）

### Company（自社＝発信者）
- **武器①: ファンとしての熱量と当事者性。** チケット落選の悔しささえ燃料になる。「本物のファンが本気で悔しがってる」は演技で作れない
- **武器②: AI・データ分析。** 歌詞分析・セトリ予測・ストリーミングデータ検証など、音楽理論ゼロでできる独自コンテンツ。演奏系でこれを持つ競合はいない
- **武器③: 「実は経営者」ギャップ。** 僕、フォルテ（マッチョ×ピアノ・30.7万人）が実証した属性ギャップの型。種明かしのタイミング自体が演出資産
- **武器④: 等身大のピアノ。** 「習ってたレベル」は弱点ではなく親近感。「俺でも弾けるかも」と思わせる距離の近さは、超絶技巧勢には出せない
- 制約: 技巧・理論は封印（確定）／可処分時間／トーク力は未検証（Phase 1で検証する項目）

## 2. STP

### Segmentation

| セグメント | 特徴 | 感情の強さ |
|---|---|---|
| a. サカナクションのコアファン | ライブ遠征・全曲聴いてる層 | 高 |
| b. **チケット難民**（aの部分集合） | 落選続きで行き場のない悔しさを抱える | **最強・今がピーク** |
| c. ミーム新規 | 夜の踊り子/怪獣から入った。新宝島しか知らない | 中・人口拡大中 |
| d. ショート娯楽層 | アルゴリズム経由。ネタとして消費 | 低・母数最大 |
| e. AI・テック層 | AI企画・build in publicに反応 | 中・X中心 |

### Targeting
**bへ一点突破 → aに広がり → cを教育（古参の語りで沼へ） → dは入口 → eはX/AI企画で並走。**
「チケット外れた」という一言は、bには当事者の叫び、aには共感、cには「そんなに取れないんだ」という発見、dにはネタとして機能する — 全セグメントに同時に刺さるフックになっている。

### Positioning
**「日本一悔しがってるサカナクションファン」**

- ステートメント: 「チケット外れたので、ピアノ弾きながらサカナクションの話をします」
- 上手さ（技巧軸）ではなく、**愛の深さ×悔しさの共感×分析の面白さ**で覚えられる
- ポジショニングマップ上は「エンタメ・人格×専門特化」象限（[02](./02_競合分析.md) 2章）。遠坂めぐが型の有効性を実証済みで、アーティスト特化は無人

## 3. SWOT → クロスSWOT

| 内部: Strength | 内部: Weakness |
|---|---|
| S1 ファンの熱量・チケット落選の当事者性 | W1 技巧・音楽理論は使えない（封印確定） |
| S2 AI・データ分析スキル | W2 知名度ゼロ・トーク力未検証 |
| S3 「実は経営者」ギャップ | W3 稼働が限られる（代表業務） |
| S4 等身大ピアノの親近感 | W4 ショート動画文法の未習熟 |

| 外部: Opportunity | 外部: Threat |
|---|---|
| O1 夜の踊り子ミームでファン人口拡大期 | T1 ミーム鎮火・話題の賞味期限 |
| O2 チケット難民が過去最大規模で発生中 | T2 単一アーティスト依存 |
| O3 8〜10月イベント密集（サマソニ→シングル→ツアー） | T3 愚痴コンテンツの炎上リスク |
| O4 アーティスト特化チャンネルの空白 | T4 「チケット当選したらネタが消える」問題 |

**クロスSWOT（採る戦略）**
- **S1×O2**: 落選当事者×難民最大母数 ＝ 共感の一点突破。初投稿からこの軸で入る
- **S2×O3**: AIセトリ予測はツアー開幕前の予習需要ど真ん中。「予測→開幕後に答え合わせ」で2度おいしい
- **S4×W1**: 技巧封印を逆手に取り「これなら俺でも弾ける」等身大路線。練習過程もコンテンツ化
- **T3対策**: 愚痴は**愛とユーモアで包む**。バンド・運営・FCは絶対に叩かない（叩いていいのは自分の運だけ）。転売問題は事実ベースでのみ触れる
- **T4対策**: 当選したら祝勝回＋現地レポでさらに伸びる。**どっちに転んでもコンテンツになる設計**にしておく
- **T2対策**: Phase 2以降、AI分析の型を他アーティストへ拡張可能な設計に（「研究対象」を増やせるフォーマット）

## 4. コンセプトとピラー（コンセプトは確定・検証はフォーマット選び）

> v1では3コンセプトのABテストを予定していたが、本人の自己認識で軸が確定したため、**検証対象を「コンセプト選び」から「フォーマット・企画タイプの選別」に変更**する。

### ピラーA「ファントーク×ピアノ」（主軸・共感）
- 型: ピアノで簡単なリフやコードを弾きながら、サカナクションについて語る
- ネタ: チケット落選報告シリーズ／新曲・発売日リアクション／ミーム新規向けの「次に聴く曲」案内／思い出語り／ライブ予習
- 弾く曲は「弾けるアレンジ」でいい。むしろ完璧じゃないほうが人格が出る

### ピラーB「AI×サカナクション研究」（独自性・拡散）
- 型: AIやデータで検証した「結果の絵」から入るショート
- ネタ: 全歌詞の最頻出ワード分析／セトリ予測／Spotify特徴量検証／偽歌詞クイズ／ストリーミング推移
- 音楽理論不要。エンジニアの土俵に持ち込む。X・テック層への拡散も狙える

### 横串「全公開」（継続と共感の仕掛け）
- フォロワー0→1,000の全数値公開／チケット戦績トラッカー／練習過程
- 週次でX投稿、月次でショート化

### Phase 1の配分（目安）
A 6本 : B 4本 : 横串 2本 → 保存・完走・**コメント率**でフォーマット優劣を判定（[06](./06_KPI・運用.md)）

## 6. 顔出し

- トーク主体のため**声が主役**。ラジオ的に成立するので、開始時は手元＋声で問題ない
- ただしトーク型は人格への愛着がエンジンなので、**顔出しの効果は技巧型より大きい**。Phase 1のコメント欄の反応（人格への言及率）を見てPhase 2で判断
- 「実は経営者」の種明かし回は顔出し解禁と同時にやると演出効果が最大
