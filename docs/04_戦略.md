## 1. 3C分析

### Customer（誰が見るか）

| | 内容 |
|---|---|
| 中心 | 30〜50代。会社員・フリーランス・小規模事業者 |
| 状態 | 「あとで調べよう」で終わっていることが山ほどある。調べる時間はない |
| 動機 | 損したくない・恥をかきたくない・少しだけ得したい |
| 行動 | **保存する**（後で使う）。すぐには行動しない |

この層はYouTube 83〜92%、Instagram 52〜70%、TikTok 25〜40%（[01](./01_市場分析.md) 1章）。
**TikTokの平均年齢は39.2歳**なので、「若者向けだから経費の話は刺さらない」は誤り。

### Competitor（誰と比べられるか）

4類型（[02](./02_競合分析.md) 6章）。要点は**2026年にC・Dが構造的に不利になった**こと。

| 型 | 2026年の状態 |
|---|---|
| A 専門家型（税理士等） | 強い。ただし本数が出ない |
| **B 当事者型** | **強い。かつ席が空いている** |
| C アグリゲータ型 | 到達 -60〜80% |
| D AI量産型 | 収益化対象外・自動検知 |

### Company（自分は何を持っているか）

| 資産 | 使い道 |
|---|---|
| **一人社長として会社を回している実体験** | `money` の一次情報。**これが唯一かつ最大の武器** |
| エンジニアとしての実装力 | パイプラインの自作。回転数で他を上回る |
| 数字への抵抗の無さ | 全公開運用（Phase 2の素材） |
| 顔・実名を出す用意がある | Phase 3の切り札。**先に使い切らない** |

**持っていないもの**: 資格・既存フォロワー・話芸の実証。ここで戦わない。

## 2. 戦略の核 — 見た目はD、中身はB

いちばん重要な設計判断。v4でもこの構図は変えない。

```
見た目（作り方）   キャラ掛け合い＋合成音声＋自動台本   ← 類型D（規制される側）
中身（情報）       一人社長が実際にやった体験・手順・判断   ← 類型B（規制されない側）
```

v4で加わった役割: **キャラは愛着の受け皿**でもある。掛け合いは「単調な読み上げ＋
スライドショー」という再利用コンテンツ判定の回避に働き、同時にファン化の器になる。
ただし**キャラのファンはキャラのファンで終わる**ので、本人への橋（7章）が必須。

**この2つを同時に成立させる。** どちらか片方だと負ける。

| もし | 何が起きるか |
|---|---|
| 中身もDだったら（横流し情報をAIで量産） | YouTubeで収益化対象外、Instagramでおすすめ除外。**規制の直撃** |
| 作り方もBだったら（全部手作業） | 1本1.5〜2時間。週2本が限界で、**2週間でジャンル判定ができない** |

パイプラインは**勝ち筋ではなく、テストの回転数を上げる道具**（[01](./01_市場分析.md) 4-4）。
1本68秒で作れるから、3ジャンル×4本を2週間で回せる。手作業なら3ヶ月かかる。

> **だから、当てるべきは「型」であって「本数」ではない。**
> 当たった型が決まったら、生成の中身を差し替えて質を上げる（[07](./07_ロードマップ.md) Phase 2）。

## 2-2. ネタの出どころ — 創作をやめ、実話を引用する（v5）

LLMが0から書いた台本は、展開もオチも「ありそうな話」の平均値になり、つまらない。
伸びている同形式の大手（2chスレ×合成音声ショート。月間数千万再生規模）は例外なく
**実在のスレ**をソースにしている。面白さはスレが持っている。
LLMの仕事は**掛け合いへの翻案とテンポ**だけにする。

引用そのままの読み上げは「再利用コンテンツ」判定のリスクがあるため、
必ず翻案・編集を加える（2章「見た目はD、中身はB」と同じ構図。器はキャラ掛け合い、
中身は実在のスレ）。

### ソースの規約線引き（踏み外すと削除依頼・アカウント停止に直結する）

**テキストソース:**

| ソース | 転載 | 扱い |
|---|---|---|
| **おーぷん2ちゃんねる** | **自由**（投稿はパブリックドメインと規約に明記） | **meme / heisei の第一候補。直接引用してよい** |
| 5ch（なんJ等） | 運営 Loki Technology の**許可制** | 許可を取るまで直接引用しない（申請の判断は [#91](https://github.com/bashaka-sawabe/personal-sns-operation/issues/91)）。大手「なんJ民と秘密の部屋」は許可取得の前例 |
| ガールズちゃんねる・たぬき系・発言小町 等 | 規約上、許諾なき転載は**不可** | 直接引用しない。**話の構造・オチの型の参考**に留める |
| ニュース記事（F1等） | **事実の伝達は著作権保護外**（著作権法10条2項）。記事の**表現**は著作物 | 事実だけ取り、**必ず自分の言葉で解説**。記事文のコピーは一切しない |
| 公的資料・官公庁 | 政府標準利用規約 / 公開文書 | **heisei / showa の裏取り一次ソース**。出典を明記 |
| Wikipedia / レファ協 / Reddit TIL | 記述の転載は各規約に従う | **ネタの発見と出典たどり**に使い、事実は一次ソースで裏取りしてから使う |
| **定番コピペ・ネットミーム** | 起源で分かれる（下の 2-2-1） | **原文を持たず、骨格だけを台帳に置いて書き下ろす**。`tools/fetch_memes.py` が権利区分で機械的に止める |

**映像・画像ソース（チャンネル別の禁止事項）:**

| ch | 使えるもの | **絶対に使わないもの** |
|---|---|---|
| `heisei` | 汎用レトロ素材（ガラケー・ブラウン管等の実物写真）、自作イラスト | **当時のCM・番組映像、商品パッケージ、キャラクター絵**（黙認アップロードが残っているのは合法だからではない） |
| `meme` / `showa` | 現行どおり Pexels / Openverse（CC0/PD） | 他者の動画・スクショ |

「参考に留める」＝表現をコピーせず、**展開の骨格（何が起きてどう落ちるか）**だけを
学ぶこと。事実とアイデアに著作権は無いが、表現の丸写しは転載になる。

### 2-2-1. 定番コピペ・ネットミームの線引き（2026-08-09・[#205](https://github.com/bashaka-sawabe/personal-sns-operation/issues/205)）

本人の要望でレパートリーに加える。ただし**スレの引用とは扱いを完全に分ける**。
おーぷん2ちゃんねるのスレは本文を引用してよいが、定番コピペの多くは
5ch起源で転載が許可制、あるいは実写動画が元で肖像権も絡むため。

**原則: 台帳に原文を置かない。** `data/memes/` が持つのは
`skeleton`（何が起きてどう落ちるか、一文）だけで、本文は保存しない。
台本生成にも原文を渡さず、骨格から**書き下ろさせる**
（`script._meme_rules`。「原文を思い出して再現しない」を明示的に禁じている）。

| 権利区分（`rights`） | 使えるか | 扱い |
|---|---|---|
| `open2ch` | ✅ | おーぷん2ちゃんねる発。本文を引用してよい唯一の区分。それでも翻案はする |
| `5ch_paraphrase` | ✅ | 5ch起源（転載は許可制）。**骨格だけ借りて全文を書き下ろす** |
| `classic_unknown` | ✅ | 作者・初出不明の古典コピペ。許諾を取る相手がいない以上、表現は必ず書き下ろす |
| `video_unusable` | ❌ | **実写動画・放送が元**。被写体と撮影者の権利が絡む。**翻案でも使わない** |
| `rights_holder` | ❌ | 権利者が明確な作品（漫画・アニメ・楽曲）。キャラ・台詞・画のいずれも使わない |

`usable=False` の区分は `fetch_memes.check_rights()` が**採用の時点で止める**。
使う直前（`load_adopted`）にももう一度見るので、台帳を手で書き換えても通らない。

**実写動画ベースを禁止にする理由**: 骨格だけにしても、有名な動画は
「あの動画のあれ」と分かってしまい、**被写体の人物が特定される**。
本人の許諾なく笑いの対象として再演することになるので、翻案でも扱わない。
台本側でも「実在の人物・団体・番組を特定できる情報を入れない」を課している。

#### 本人が挙げた3つは全部使えない（調査結果・2026-08-09）

| ミーム | 正体 | 判定 |
|---|---|---|
| 東大医学部頭悪いおじさん | 2018年12月、JR武蔵野線の車内で叫ぶ男性を**居合わせた乗客が無断撮影**しSNSへ | ❌ `video_unusable` |
| 車掌にキレる孫悟空おばさん | 2017年4月、小田急線車内の女性を**無断撮影**しTwitterへ | ❌ `video_unusable` |
| ゲームのカード落としちゃいました | 2016年5月、バス車内の男性を**無断撮影**しTwitterへ | ❌ `video_unusable` |

**3つとも同じ構造**: 公共交通機関で不審な言動を取る私人を、第三者が無断撮影して投稿したもの。
撮影者は匿名で許諾を取る相手が辿れず、被写体3人とも身元不明で同意を取ることが物理的に不可能。
いずれも精神的な不調がうかがわれる人物で、要配慮個人情報にも触れる。
「ゲームのカード」は誤同定による名誉毀損（tehu氏が否定）まで実際に起きている。
**テキストのコピペではないので翻案の余地も無い。**

#### 有名コピペは二極で、中間がほとんど無い

調査で分かったのは、有名コピペのほぼ全てが次のどちらかということ:

- **原典不明・作者不明**（ぬるぽ／白木屋／スーパーハカー／モナー等）
  → 許諾を取る相手がいない。ただし**「作者不明＝安全」ではない**。
  ホテル・ジャンキーズ事件（東京地判 平成14年4月15日）で、匿名でも著作物性は
  否定されないと判断されている
- **書籍化・映像化済みで権利が固い**（電車男／師匠シリーズ／きさらぎ駅／
  ブラック会社／ドラえもん最終話／ルイズ／マサラタウン）→ 使わない
- 例外的に**作者が判明していて存命**なもの（吉野家コピペ＝新爆氏。本人が取材に応じている）
  → 原文の再利用は許諾が要る。**使わない**

さらに、著作権法32条の引用は「改変せずそのまま載せる」ことが前提なので、
**寸劇化（翻案）は引用では逃げられない**。

#### 5ch由来を触るなら公式の許諾スキームに乗る（[#91](https://github.com/bashaka-sawabe/personal-sns-operation/issues/91) の判断材料）

5ch公式（`5ch.io/matome.html`）が動画チャンネル向けに条件を明記している:

> ・5ch公式YouTubeチャンネルの登録／公式SNSのフォロー
> ・**コンテンツを使用して制作された動画を毎月1本の割合で納品をする事**
> ・**当チャンネルYouTubeメンバーシップへの加入をする事**

無許諾利用には「DMCA違反の通報も積極的に行う」と明記。
**毎月1本の納品とメンバーシップ加入が条件なので、割に合わない。**
`5ch_paraphrase`（骨格だけ翻案）に留め、原文には触らない。

#### 結論: 一番筋がいいのは「型を借りて中身を自作」

有名コピペが二極である以上、**特定のコピペを狙うより、型（新入社員が指示を
極端に literal に実行する／店員と客のすれ違い／先生怒らないから）だけを借りて
中身を書き下ろす**のが、権利面で安全かつ再現性が高い。
構造・シチュエーションに著作権は無い。
**heisei / showa は裏取り（一次ソースURL）が無い事実ネタを台本にしない**（`tools/fetch_facts.py` が機械的に強制する。[#103](https://github.com/bashaka-sawabe/personal-sns-operation/issues/103)）。

### 演出・形式の判断基準（v5で明文化）

**「登録者10万人超の同形式チャンネルがやっているか」を判断の既定値にする。**
独自の工夫は、大手がやっていない理由を説明できるときだけ採用する
（例: シーンごとのセクション見出しは大手に存在しない → 廃止。[#93](https://github.com/bashaka-sawabe/personal-sns-operation/issues/93)）。

視聴体験は**ドーパミン設計**で考える:

- 会話のラリーは詰める（無音の「間」を最小にする。[#90](https://github.com/bashaka-sawabe/personal-sns-operation/issues/90)）
- シーン1でオチへの期待を作る（オチ逆算。[05](./05_コンテンツ企画.md) 2章）
- 2〜3秒に1回の視覚変化（[03](./03_トレンド調査.md)）に効果音・パンチインを重ねる

## 4. チャンネル設計 — 3チャンネルで回す（v6.1）

2025〜26年のYouTubeはチャンネル全体の一貫性を評価するため、
性質の違う内容を1チャンネルに混ぜない。

> ⚠️ **同じ型では回さない**（2026-08-02改訂）。ジャンルごとに勝ち方が違うことが
> 実測で判明した（[02](./02_競合分析.md) 1章）。尺は meme 26.7秒 / trivia 55〜59秒 /
> heisei 2〜4分、フックも締めも別物。**演出はチャンネル別に作り込む。**

| ch | ペルソナ | 仮説 | 弱点 |
|---|---|---|---|
| `meme` | ユウ（24・ミーム好き） | **拡散力とキャラ人気**のテスト。コメント率が最も出る。ソース（open2ch）との相性が最良 | 本人への信用移行が最も遠い |
| ~~`trivia`~~ | サトシ（42・普通の会社員） | ~~**母数最大**。「へぇ＋ちょっと得」は完走されやすい~~ **廃止（2026-08-08・[#192](https://github.com/bashaka-sawabe/personal-sns-operation/issues/192)）** | 保存・コメントが弱い層で、差別化が裏取りの信頼性頼みだった |
| `heisei` | アヤ（35・平成小学生世代） | **コメント欄が伸びる**（懐古は語りたくなる）。open2chの懐かしスレと相性が良い | 映像・画像規約の制約が最も厳しい（当時素材が使えない） |

**3つで固定する。** これ以上増やすと1チャンネルあたりの本数が減って判定できない。
現役は meme / heisei / showa。サトシは一時 trivia の主ペルソナに昇格したが廃止で退場し、
「どの動画もサトシが見て分かるか」という**全チャンネル共通の分かりやすさの下限**
としての役割は継続する。

### `f1` を廃止した理由（本人決定 2026-08-02）

企画としては「ずんだもん×F1は最大手8,070人の空白地帯」という魅力があったが、
調査の結果、次の3つが揃って成立しないと判断した:

1. **データが商用不可** — Jolpica-F1 のデータは CC BY-NC-SA 4.0（非営利限定）。
   コードの Apache 2.0 とは別物。FastF1 の MIT もコードのみでデータは免責されない
2. **F1公式ガイドラインがLLM利用を明示的に禁止**（TDM/AI条項）。
   公式RSSをLLMに渡して台本を作るこのパイプラインの根幹と衝突する
3. **映像なしで成功した日本語チャンネルの前例がない** — フジテレビ公式ですら
   映像なし企画は6,706回、映像ありハイライトは52万回（[02](./02_競合分析.md) 5章）

加えてチャンネル名・タイトル冒頭の「F1」は2024年にC&D送付の実例があり、
運用上の制約も大きい。**やるなら権利を固めた別企画として立て直す。**

IG・Threadsは勝ちチャンネル確定まで**1アカウント運用**。

## 7. 本人への移行設計（Phase 1 → 2 → 3 の橋）

**キャラのファンはキャラのファンで終わる。** ずんだもんが100万回再生されても、
モテるのはずんだもんである。最終ゴール（本人への好感移行）には橋の設計が必須で、
**ずんだもんは本人に変換できない**（声も人格も借り物）ため、橋は「共演」方式にする。

| 仕込み | 具体 | いつから |
|---|---|---|
| **キャラに「中の人」を語らせる** | `biz`:「このチャンネルの中の人（一人社長）も、実際に同じ失敗をしたのだ」。1本1回 | **Phase 1の最初から** |
| 体験を中の人のものにする | 一般論ではなく実際にやった手順・失敗（一次情報スロット） | **Phase 1の最初から** |
| プロフィールに中の人の存在を書く | 「一人社長が作っています」 | **Phase 1の最初から** |
| **本人が共演し始める** | 声・シルエットでキャラと掛け合い。キャラは本人をいじる相棒役に回る | Phase 2 |
| 全公開 | フォロワー数・数字の推移を出す | Phase 2 |
| 種明かし | 「実は経営者・エンジニア」 | Phase 2。**先に使い切らない** |
| 顔・実名で共演 | キャラに積もった「面白い・頼れる」が隣の本人に移る | Phase 3（[07](./07_ロードマップ.md)） |

**橋の効きはプロフィールアクセス率で測る**（「中の人って誰？」の数）。
コメント率はキャラへの愛着、プロフィールアクセス率は本人への関心。**両方見る。**

## 8. 本業との距離

- **会社の具体的な金額（税額・社会保険料・役員報酬などの実額）はコンテンツで一切公開しない**
  （本人決定 2026-07-30）。会計データ（freee等）を台本素材に流用することもしない。
  一次情報＝差別化は金額ではなく**「実際にやった人の体験・手順・判断・失敗談」**で出す
- 会社名・サービス名を先に出さない。**Phase 2の種明かしまで取っておく**
- **素材規約上の制約もある**: ずんだもん等のキャラの法人利用・スポンサー接続は要契約
  （[08](./08_自動化.md)）。運用は個人名義で行い、**会社名と接続する前に許諾を再確認する**
- 個別の税務相談・法律相談はしない（資格の線引き。[01](./01_市場分析.md) 6章）
- 実名公開は**取り消せない**。Phase 3で本業との接続込みで決める
