| | ① ユウ → `meme` | ② サトシ → ~~`trivia`~~（廃止・下限チェック役のみ） | ③ アヤ → `heisei` |
|---|---|---|---|
| 像 | 24歳・若手。ニコニコ文化圏育ち | 42歳・地方の会社員・既婚 | 35歳・平成小学生世代の会社員 |
| 動機 | **ネタと文脈**を消費したい | 強い悩みはない。「へぇ」と少しの得 | 「あったあった！」と語りたい |
| SNS行動 | YouTube・X・ニコニコ。**コメント欄で大喜利** | YouTubeのみ。完走するがコメント・保存はしない | IG・YouTube。**コメントで思い出を語る** |
| 刺さる型 | キャラ掛け合いの妙・元ネタの文脈 | 30秒で「へぇ＋ちょっと得」 | 共感の懐古＋「そういえばアレどうなった？」 |

## 2. 台本の型 — キャラ掛け合いの5シーン

5シーン構成は維持する（型の固定は視聴者の学習を促す。[02](./02_競合分析.md) 1章）。
**中身がナレーションから2キャラの会話に変わる。**

**v5以降、0からの創作はしない。** `meme` / `heisei` は採用スレ（`data/threads/`・
人または自動採用で選別済み）の翻案、`heisei` / `showa` は裏取り済みの事実が入力になる。
台本は**オチから逆算する**: まず一番面白い点（スレのオチ／事実の意外さ／ニュースの
引っかかり）を一文で特定してシーン5に置き、シーン1のフックは「オチへの期待」を作る。
オチを一文で言えないネタは、そもそも採用しない（3章）。
会話のラリーは詰める。説明口調の分担読みは禁止（ドーパミン設計。[04](./04_戦略.md) 2-2章）。

| # | 役割 | 中身 | 秒数の目安 |
|---|---|---|---|
| 1 | **フック** | 3秒以内に「何の話か」。片方の悲鳴・疑問で入る | 3〜5秒 |
| 2 | 本編① | あるある・状況の再現（掛け合い） | 5〜8秒 |
| 3 | 本編② | 核心・理由 | 5〜8秒 |
| 4 | 本編③ | チャンネル別の本体（下記） | 5〜8秒 |
| 5 | 締め | 持ち帰れる一言＋問いかけ | 3〜5秒 |

### チャンネル別の型

| ch | 型 | シーン4に入るもの | 配役 |
|---|---|---|---|
| `meme` | **スレ引用 → 寸劇・ツッコミ → パワーワードで終わる** | オチの直前の展開（スレの転換点） | ずんだもん（ボケ）×めたん（ツッコミ・解説） |
| `heisei` | **「◯◯選」リスト**（主）／「あれ覚えてる？」掛け合い（従） | リストは各ネタを16字で投げる。掛け合いは当時の実像 | めたん（懐かしむ先輩）×ずんだもん（平成を知らない後輩） |
| `showa` | **昭和の熱血経営者の実話を寸劇で再現 → 令和目線の総ツッコミ** | 無茶の中身（裏取り済みの逸話） | 青山龍星（熱血）＝経営者 × ずんだもん＝令和の視点 |

### 説明ではなく寸劇にする（全チャンネル共通・2026-08-05）

本人評価「全部説明になっている。情報を教えているだけ」。
原因を調べたら、**キャラがスレの外にいて報告していた**。

```
✗ め「長袖で肌も出さない妻だそうよ」        ← 伝聞
✗ め「そこへ『着ないなら離婚と脅せ』と」     ← 報告
○ ず「嫁がスカート全く着ないのだ！」        ← 本人が言う
○ 玄野「履かないなら離婚だ、って脅せよ」     ← レス民が言う
```

プロンプトの語彙頻度も裏付けになった: 形式109回 / 正確さ36回 / **感情わずか4回**。
「何を感じさせるか」を決める仕組みが無かった。

| ルール | 中身 |
|---|---|
| **感情を先に決める** | 台本に `emotion`（笑い/切なさ/呆れ/共感/怒り）を1つ。**情報はその乗り物**であって目的ではない |
| **キャラを中に入れる** | ずんだもん＝スレ主、脇役＝レス民。**その場で喋らせる**。「〜だそうよ」「そこへ〜と」は禁止 |
| **削りすぎない** | 下品さ・バカバカしさ・自虐・見栄・的外れな助言は**残す**。落とすのは誹謗中傷・個人特定・差別・違法行為の推奨だけ |

> 「敬意を払う」のは**元ネタの文化**に対してであって、
> 登場人物を上品に描き直すことではない。上品にまとめると事実だけが残って説明文になる。

### 掛け合いを平坦にしない（全チャンネル共通・2026-08-03）

生成物313行を分析したら、**ずんだもんの94%が「〜のだ」で終わり、中身は
「ないのだ」「しいのだ」など形容詞1語の相槌**だった。2人のセリフ長もほぼ同じで、
説明文の分担読みになっていた（本人評価「スムーズすぎて人間らしさがない」）。

| ルール | 中身 |
|---|---|
| **1話題を2〜3往復させる** | **シーン＝話題**。その話題の中で会話を往復させてから次へ。話題を増やすほど掛け合いは薄くなる |
| **一問一答にしない** | 「情報→質問→回答」の繰り返しはQ&Aであって会話ではない。**質問は1本に最大2回** |
| **2人に意見を持たせる** | 各シーンに最低1つ、立場を表明する行（「ボクなら」「〜と思う」「あなたは〜でしょ」）。**1本に1回は意見が食い違う場面**を作る |
| **相槌を書かない** | 感想だけで終わる行を1行も入れない。口を開くなら疑問・たとえ・自分の話・反論・飛躍を足す |
| **語尾を連続させない** | 同じ語尾を2行以上続けない。疑問形・体言止め・言い切り・途中で切るを混ぜる |
| **役割を非対称に** | 情報を持つ側は25〜35字で数字と固有名詞を出す。聞き役は5〜20字で食い気味に差し込む |
| **スムーズに進めない** | 見当違い・脱線して戻る・納得しないを1本に最低2回 |
| **割り込む** | 言い切る前に奪う。奪われる行は末尾を `──` で終え、次を別の話者が食い気味に返す。**1本に最低2回** |
| **一人に長く喋らせる** | 同じ人が続けて2行以上喋る場面を**1本に最低1回**。そこを我慢できずに割り込ませる |
| **感心して終わらない** | 「勉強になった」で終わると何も残らない。引っかかりか笑いか次の疑問を残す |

`script.py` の `dialogue_issues()` が生成後に自動チェックし、
相槌・語尾の連続・**質問過多（40%超）**・**意見表明の不足**・字数の非対称性の欠如を
警告する（止めはしない）。

> 2026-08-03に3回作り直した。学んだこと:
> 1. 「疑問形を増やす」と質問だらけになる。**足すべきは質問ではなく意見**
> 2. 意見を足しても、**1話題1往復では一問一答のまま**。
>    話題の数を減らし、1つを掘るのが掛け合いの条件（シーン数は `style.scenes`）

#### 均等割りをやめた（2026-08-05・[#143](https://github.com/bashaka-sawabe/personal-sns-operation/issues/143)）

本人評価「複数人でわちゃわちゃ会話してるのがいいのに」「1人が喋る量が少なすぎる」。
原因は**人数ではなく構造**だった。

1. **均等割り**: 「各シーン4〜6行」と指定していたため、どのシーンも同じ密度になり、山が作れない
2. **行長制限**: セリフ35字以内（meme は20字以内）で、**全員が一言コメント係**になる
3. **割り込みが1回も無い**: 5人いても順番を守って話しており、司会が順に振っているだけ

そこで**シーンごとの行数指定を捨て**、行の長さも揃えないことにした。
差し込みは5〜15字、語る場面は40字まで。

**割り込みは書き方を決めて機械で数える。** 奪われる行の末尾を `──` で終え、
次の行を別の話者が返す形にする。この記号は**字幕にだけ残し、読み上げには渡さない**
（末尾の無音も落とすので、音でも「言い切る前に奪われた」になる）。

> ⚠️ **行長を緩めると尺が伸びる。** 最初の生成は 43.5秒（ベンチは26〜32秒）だった。
> 尺は行数では決まらないので、`style.max_chars`（セリフの合計字数）で縛っている。
> `meme` は230字＝約29秒。

### `meme` は掲示板の記号を捨てる

登録者51.2万のチャンネルはタイトルに `www` を0%・`【悲報】` を0%しか使っていない。
逆にそれらを使う従来型は直近2,000〜3,000回まで落ちている（[02](./02_競合分析.md) 2章）。

- `www` `【悲報】` `ンゴ` などのなんJ語を caption に使わない。レス番号・ID・名前欄も出さない
- caption は **`【4〜6字の名詞句】`＋言い切る短文**（【ルールの盲点】【妙な説得力】…）
- **オチは「コメントで復唱できるパワーワード1個」に集約し、説明を足さずに終わる**
- 尺は26秒前後。セリフ12行・合計150字以内

### 事実もの（heisei / showa）は「どこ情報？」に必ず答える

事実ネタは間違えた瞬間にコメント欄で刺されて信用が飛ぶ。**一次ソースの裏取りが無い
ネタは台本にしない**（`tools/fetch_facts.py` が機械的に強制。[#103](https://github.com/bashaka-sawabe/personal-sns-operation/issues/103)）。
シーン4で出典に軽く触れる（「◯◯省の資料に載ってる話なのだ」程度。読み上げない）。

### `heisei` は「知らない後輩に説明する」構図で懐古を外に開く

懐古だけだと同世代にしか刺さらない。ずんだもん（平成を知らない）に説明する形にすると、
若い視聴者にも「そんな時代があったのか」で成立する。

フックは種明かし型とは正反対の**「あれ、覚えてる？」型**（知らない話の種明かしではなく、
知っている話の掘り起こし）。締めは「今どうなったか」か「当時は当たり前だった」の落差。
**年代・製品名は裏取り済みのものだけを言う**（世代ネタの誤りはコメント欄で一発で刺される）。
懐かしむ対象を馬鹿にしない・特定企業を貶さない。

**主力は「◯◯選」のリスト形式**（`--facts` に複数指定）。実測で
1本1ネタの情報提示型は185本出して1,000〜3,000回、リスト形式は登録者1.12万で21万回
（[02](./02_競合分析.md) 4章）。

- タイトルは「◯◯年生まれ**位**が懐かしい△△○選」。**「位」を必ず入れる**（前後10年を取り込む）
- 各ネタのセリフは**16字以内**。解説を入れない
- リストは全部を網羅しない。**入りきらないものを残す**のが正解
  （視聴者が「◯◯が無い」と補完コメントを打つ余地。コメントの正体は
  「年齢の名乗り」と「リストの穴埋め」の2つ）

## 3. ネタ選びの基準

**全チャンネル共通:**

1. **オチ（一番面白い点）を一文で言えるネタだけ採用する**
2. 15〜45秒で語り切れる（1本1ネタ・1オチ）
3. 実在人物の誹謗中傷・個人特定・他クリエイター批評はしない（[02](./02_競合分析.md) 7章）
4. 採用は人の目視が基本だが、在庫が足りない日は `daily_run.py` が候補から
   **自動採用**してよい（2026-08-08 本人決定・[#191](https://github.com/bashaka-sawabe/personal-sns-operation/issues/191)。条件は [08](./08_自動化.md) 1章）
5. ペルソナの顔で選ぶ。「この人がこれを最後まで見るか？」

### 引用スレの採用基準（`meme` / 引用型・2026-08-05に強制化）

**この節ができるまで、採用基準はどこにも書かれていなかった。**
`fetch_threads.py` にあったのは実況スレ等を落とす除外パターンだけで、
採用は勘だった。結果、オチの無いスレから動画を作り、本人評価
「そもそも選定にセンスがなさすぎる。どういう基準で選定してんの？」（2026-08-05）。

ロンロンの天秤（51.2万）は「**コメントで復唱できる語が1個取れるか**」でスレを選んでいる
（[02](./02_競合分析.md) 2章）。26.7秒はその1語を届けるための助走でしかない。
面白さは演出でも会話術でもなく、**この1語を持つスレを引けるか**で決まる。

そこで `--adopt` は次の3つを要求し、満たさないスレを**コードで拒否する**。

| 条件 | 理由 |
|---|---|
| パワーワードが **2〜14字** | コメント欄に書き写せない長さでは復唱されない（実例「シャマルピー」6字） |
| パワーワードが **スレ本文に実在する** | こちらで作った造語を復唱させても滑る。**探すもので、作るものではない** |
| パワーワードに **掲示板の内輪語を含まない** | `ワイ` `イッチ` `おんJ` `ｗｗ` `【悲報】` 等。板を知らない層に届かず、裾野が住人で頭打ちになる |
| オチが **10〜60字の一文**で言える | 一文で言えないスレは、動画にしても着地しない |

```bash
.venv/bin/python tools/fetch_threads.py --adopt livejupiter-1785667068 \
    --powerword "Gパン…エｯｯ！" \
    --ochi "スカートを履かせたい夫が、お前が履けと返されて終わる"
```

採用理由は `data/threads/<id>.json` に残り、`--list` で一覧できる。
**基準ができる前に採用したスレは `load_adopted()` が拒否する**ので、
台本生成に流すには採用し直す必要がある。

**チャンネル別:**

| ch | 基準 |
|---|---|
| `meme` | 引用元は**転載自由ソースのみ**（[04](./04_戦略.md) 2-2章）。**「コメントで復唱できるパワーワードが1個作れるか」がスレ選定の第一基準**（[02](./02_競合分析.md) 2章）。収集は `tools/fetch_threads.py` |
| `heisei` | **事実ベースが主**（`tools/fetch_facts.py --channel heisei`。年代・製品名は裏取り必須）。懐かしスレは出現頻度が低く旬に依存するため、スレ待ちにしない（[#113](https://github.com/bashaka-sawabe/personal-sns-operation/issues/113)）。良いスレが出た日は `--thread` の引用型でも作れる。**懐かしむ対象を馬鹿にしない・特定企業を貶さない** |
| `showa` | **一次ソースで裏取りできた実在の逸話のみ**。「今ならアウト」の落差が大きいものを優先。**本人を貶めない**（存命の関係者・遺族が見ても許容される線） |
| `trivia`（廃止） | **一次ソースで裏取りできた事実のみ**（`tools/fetch_facts.py` が裏取り無しの採用を拒否する）。裏取りの優先順位: **官公庁・政府統計・学術機関 > 信頼できる一次報道 > Wikipedia経由で原典にたどる**。「信じられないが本当」の落差が大きいものを優先。医療・投資の助言に踏み込まない |

### `girls` — ミサキ向け・主戦場候補

| テーマ | 狙い | 持ち帰る一言の種 |
|---|---|---|
| 飲み会の上手な断り方 | 実用性が高く保存されやすい | 先に次を約束する |
| 既読スルーされたときの考え方 | 母数最大の悩み。共感の入口 | 返信は相手のタイミングの問題 |
| 同期と比べて落ち込む夜の抜け出し方 | 「自分だけじゃない」で共感 | 比べる相手を昨日の自分にする |
| 「いい人止まり」で終わる人の共通点 | 恋愛文脈。タイトルで押せる | 好意は小出しに見せていい |

### `biz` — ケンタ向け・信用の土台

| テーマ | 狙い | 一次情報の置き所 |
|---|---|---|
| 法人化で税金は減るのか | 起業検討層に刺さる本命 | **法人化して実際に変わったこと・想定外だったこと** |
| 手取りが少ない本当の理由 | 会社員にも刺さる（会社負担の社保） | 保険料・税金の引かれ方で実際に誤算だったこと |
| 独立1年目に踏む落とし穴 | 「先に知りたかった」の典型 | 実際に踏んだ手順・失敗 |
| 角を立てない仕事の断り方 | 経営者は断る回数が多い | 実際に使っている言い回し |

### `meme` — ユウ向け・拡散力とキャラ人気のテスト

| テーマ | 狙い |
|---|---|
| 猫ミームの元ネタ、全部知ってる？ | ど真ん中の題材。検索も効く |
| OIIA（回転猫）はなぜ2億回再生されたのか | 数字フックで非ミーム層にも届く |
| インターネット老人会: Flash黄金時代 | 懐かしさはコメントが伸びる |
| Xあるある寸劇 | キャラの演技力＝掛け合いの質のテスト |

| 本数 | 12本を2週間で。YouTubeとTikTokは**チャンネル別**、IG・Threadsは当面1アカウントに全部 |
| YouTube | クォータの都合で**1日6本が上限**。2日に分ける（[09](./09_パイプライン.md)） |
| 公開範囲 | アップロード時に**22:00 / 23:00 JSTで公開予約**（1ch2本/日）。出したくない本は公開までに `--unreserve` で外す（[09](./09_パイプライン.md) 2-3章） |
| 公開直後 | **30〜60分のコメント返信は手動**（[08](./08_自動化.md) 2章） |

## 6. 投稿前チェックリスト（毎回・全項目）

### 内容

- [ ] シーン1が**リアクションから開幕**している（状況説明で始まっていない）
- [ ] 1本1ネタ・1オチになっている
- [ ] **サトシが見て30秒で分かる**（専門用語を裸で使っていない）
- [ ] オチのあとに蛇足（解説・まとめ）が付いていない

### ロンロン型（meme / heisei。#166、根拠は [02](./02_競合分析.md) 2-2章）

「キチガイだが知性がある」を、雰囲気ではなく次の○×で判定する:

- [ ] **壊れている前提がちょうど1個**ある（0個=普通の話でつまらない。2個以上=出鱈目で知性が消える）
- [ ] 壊れ方が**言葉かロジック**である（同音異義／多義語の全力実行／制度ハック／語彙の接合ミス。
      「大声を出す」「変顔をする」のような感情・身体の壊れ方はロンロン型ではない）
- [ ] ボケの当事者が**最後まで大真面目**（照れ・自覚・ネタバラシをしていない）
- [ ] 壊れた前提の上で、**全員の行動が論理的**（当事者なりの筋が通っている）
- [ ] 状況説明が**会話内の質問への回答**として出てくる（ナレーション的な行がない）
- [ ] オチが「精密な名づけ・例え」か「冷静な一般化」のどちらかで、**その行がpowerword**になっている
- [ ] 異常に具体的なディテールが1個ある（数字か固有の状況。ネタの範囲内）
- [ ] ネットスラングが**台詞の中に**自然に入っている（caption・タイトルには無い）

### 金太郎/半沢型（showa のみ。#167。ロンロン型は適用しない）

参照はサラリーマン金太郎・半沢直樹。「時代のイカれ方」を次の○×で判定する:

- [ ] **誇張していない**（実話の範囲のまま。盛ると「実話なのにこれ」の強度が消える）
- [ ] **昭和の常識を全員が大真面目に運用している**（熱血側だけでなく周囲も。
      時代を疑ってよいのは令和視点のずんだもんだけ）
- [ ] **対決の構図が1つ**ある（部下vs社長、現場vs本社、職人vs制度）
- [ ] クライマックスに**啖呵が1回**あり（20字以内）、その行が powerword になっている
- [ ] 熱血側が憎めない（部下想いの一面か、自分が折れる場面がある）
- [ ] 締めに「今なら考えられない」と「この人がいたから今がある」の**両方**が残っている

### 事実

- [ ] `showa`: **一次ソースのURLが台本に記録されている**。制度・数字は「2026年時点」と分かる書き方で断定しない
- [ ] `heisei`: 年代・名称の事実関係を確認した（世代ネタの誤りはコメント欄で一発で刺される）
- [ ] `meme`: 元ネタの出典を確認した（誤った元ネタ紹介はこの層に一発で見抜かれる）
- [ ] 医療・投資・税務の助言に踏み込んでいない（[01](./01_市場分析.md) 6章）

### 声・配役

- [ ] **声の性別と役柄・アイコンの性別が一致している**（男性役に女性ボイス等の不一致は一発で違和感になる。本人指摘 2026-08-06）
- [ ] 1本の動画が「ずんだもん×めたん」の2声だけになっていない（キャスト固定は量産感の象徴。チャンネルのcastは3声以上で回す）

### 表示・規約

- [ ] **クレジット表記**がある: `VOICEVOX:ずんだもん` `VOICEVOX:四国めたん` 等（[08](./08_自動化.md)）
      ※ 話者アイコンとBGM以外の素材にクレジットは要らない（#222）
- [ ] TikTokで**AI生成ラベル**を付けた（合成音声を使っている間は必須。[01](./01_市場分析.md) 4章）
      ※ YouTubeは Studio の「AIの使用」欄で扱う。**説明文には書かない**（#222）
- [ ] 他クリエイターの批評・専門家を貶める煽りが入っていない（[02](./02_競合分析.md) 7章）
- [ ] 会社名・サービス名を出していない（**素材規約上も要許諾**。[08](./08_自動化.md)）
- [ ] `meme` / `heisei`: 引用元スレが**転載自由ソース**である（[04](./04_戦略.md) 2-2章）
- [ ] `heisei`: 当時のCM・番組映像・商品パッケージ・キャラ絵を使っていない

> **事実確認は飛ばさない。** お金の話で数字を間違えると、その1本が滑るだけでなく
> チャンネルの信用ごと飛ぶ。台本はAIが書くが、**確認は人がやる**。

## 7. ネタの補充

| 補充元 | 拾い方 |
|---|---|
