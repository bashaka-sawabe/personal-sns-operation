## 1. ペルソナ — チャンネルはここから逆算する

テーマは「ジャンル」からではなく**ペルソナ（誰が見るか）から逆算する**。

| | ① ミサキ → `girls` | ② ケンタ → `biz` | ③ サトシ → **chなし** | ④ ユウ → `meme` |
|---|---|---|---|---|
| 像 | 26歳・都内会社員3年目 | 34歳・独立2年目、法人化を迷い中 | 42歳・地方の会社員・既婚 | 24歳・若手。ニコニコ文化圏育ち |
| 悩み | 職場の人間関係・恋愛・「感じよく断りたい」 | 税金・社保・経費。「知らないと損」への恐怖 | 強い悩みはない。「あとで調べよう」が山積み | 悩みではなく**ネタと文脈**を消費したい |
| SNS行動 | IG Reels・TikTok中心。**保存魔** | YouTube検索・X。実額・実例に反応 | YouTubeのみ。完走するがコメント・保存はしない | YouTube・X・ニコニコ。**コメント欄で大喜利** |
| 刺さる型 | 「わかる〜」＋明日使える一言 | 「同じ立場の先輩の実額」 | 30秒で「へぇ＋ちょっと得」 | キャラ掛け合いの妙・元ネタの文脈 |
| ファン化 | 中（保存→フォロー） | **高（種明かしで最も動く本命）** | 低 | **最速（キャラのファンになる）** |

### ③サトシに専用チャンネルを作らない理由

特定の悩みで検索・保存しない層なので、専用コンテンツを作っても刺さらない。
代わりに**全チャンネル共通の「分かりやすさの下限」**として使う:
どの台本も「サトシが見て30秒で分かるか」を通す。

## 2. 台本の型 — キャラ掛け合いの5シーン

5シーン構成は維持する（型の固定は視聴者の学習を促す。[02](./02_競合分析.md) 4章）。
**中身がナレーションから2キャラの会話に変わる。**

| # | 役割 | 中身 | 秒数の目安 |
|---|---|---|---|
| 1 | **フック** | 3秒以内に「何の話か」。片方の悲鳴・疑問で入る | 3〜5秒 |
| 2 | 本編① | あるある・状況の再現（掛け合い） | 5〜8秒 |
| 3 | 本編② | 核心・理由 | 5〜8秒 |
| 4 | 本編③ | チャンネル別の本体（下記） | 5〜8秒 |
| 5 | 締め | 持ち帰れる一言＋問いかけ | 3〜5秒 |

### チャンネル別の型

| ch | 型 | シーン4に入るもの | 配役 |
|---|---|---|---|
| `girls` | **共感フック → 最後に持ち帰れる一言** | めたん先輩の「使える一言」。**共感だけで終わらせない**（保存する理由を作る） | めたん（先輩）×ずんだもん（後輩） |
| `biz` | 質問 → ホンネ回答 | **一次情報**。キャラに「中の人」を語らせる:「このチャンネルの**中の人（一人社長）は**、実際〇〇円だったのだ」 | ずんだもん（困ってる人）×めたん（教える人） |
| `meme` | ネタ・元ネタ解説・寸劇 | 元ネタの出典・文脈 | 自由 |

### `girls` の締めは説教にしない

「わかる〜」だけの動画は見て気持ちいいが**保存する理由がない**（保存率が動かない）。
かといって先輩が正論を語ると説教になる。**会話のノリのまま、一言だけ持たせる**:

> ずんだもん「断りたいけど角が立つのだ…」（共感パート）
> めたん「『次は絶対行きたいから今日は…』って、**先に次を約束する**のよ」（持ち帰る一言）

### `biz` の「中の人」言及は毎回1回入れる

本人への橋（[00](./00_サマリー.md)）の仕込み。多用すると宣伝臭くなるので**1本1回**。
言及したら数字は必ず実額（一次情報スロット。[09](./09_パイプライン.md) 2-2）。

## 3. テーマ選びの基準

1. **ペルソナの顔を思い浮かべて選ぶ**。「ミサキがこれを保存するか？」
2. 15秒で結論まで言い切れること。言い切れないものは分割する
3. `biz` は「実際に会社を回している人しか言えないこと」に寄せる
4. 「〇選」にしない。**1本1論点**
5. `meme` は元ネタに敬意を払う。他クリエイターの批評はしない（[02](./02_競合分析.md) 6章）

## 4. 2週間テストの12本（3チャンネル×4本）

正本は [data/themes.md](../data/themes.md)。ここでは**各テーマの狙い**を書く。

### `girls` — ミサキ向け・主戦場候補

| テーマ | 狙い | 持ち帰る一言の種 |
|---|---|---|
| 飲み会の上手な断り方 | 実用性が高く保存されやすい | 先に次を約束する |
| 既読スルーされたときの考え方 | 母数最大の悩み。共感の入口 | 返信は相手のタイミングの問題 |
| 同期と比べて落ち込む夜の抜け出し方 | 「自分だけじゃない」で共感 | 比べる相手を昨日の自分にする |
| 「いい人止まり」で終わる人の共通点 | 恋愛文脈。タイトルで押せる | 好意は小出しに見せていい |

### `biz` — ケンタ向け・信用の土台

| テーマ | 狙い | 一次情報の置き所 |
|---|---|---|
| 法人化で税金はいくら変わったか | 起業検討層に刺さる本命 | **法人化前後の実額** |
| 手取りが少ない本当の理由 | 会社員にも刺さる（会社負担の社保） | 自社の社会保険料の実額 |
| 独立1年目に踏む落とし穴 | 「先に知りたかった」の典型 | 実際に踏んだ手順・失敗 |
| 角を立てない仕事の断り方 | 経営者は断る回数が多い | 実際に使っている言い回し |

### `meme` — ユウ向け・拡散力とキャラ人気のテスト

| テーマ | 狙い |
|---|---|
| 猫ミームの元ネタ、全部知ってる？ | ど真ん中の題材。検索も効く |
| OIIA（回転猫）はなぜ2億回再生されたのか | 数字フックで非ミーム層にも届く |
| インターネット老人会: Flash黄金時代 | 懐かしさはコメントが伸びる |
| Xあるある寸劇 | キャラの演技力＝掛け合いの質のテスト |

## 5. 投稿の運用

| | |
|---|---|
| 本数 | 12本を2週間で。YouTubeは**チャンネル別**、他PFは当面1アカウントに全部 |
| YouTube | クォータの都合で**1日6本が上限**。2日に分ける（[09](./09_パイプライン.md)） |
| 公開範囲 | まず**限定公開**。中身を見てから公開に切り替える |
| 投稿直後 | **30〜60分のコメント返信は手動**（[08](./08_自動化.md) 2章） |

## 6. 投稿前チェックリスト（毎回・全項目）

### 内容

- [ ] シーン1が**3秒以内**に「何の話か」を言い切っている
- [ ] 1本1論点になっている
- [ ] **③サトシが見て30秒で分かる**（専門用語を裸で使っていない）
- [ ] `girls`: 最後に持ち帰れる一言があり、説教になっていない
- [ ] `biz`: 一次情報が入っている。「中の人」言及が1回ある
- [ ] 「〇選」になっていない

### 事実（`biz` は特に厳格に）

- [ ] 税率・上限額・要件を**一次ソース**（国税庁・日本年金機構・厚労省）で確認した
- [ ] **「2026年時点」と明示**している
- [ ] 断定していない（条件付きで言っている）
- [ ] 個別の税務相談・法律相談になっていない（**資格の線引き**。[01](./01_市場分析.md) 6章）
- [ ] 実例を**一般化していない**（「中の人の場合は」と限定している）
- [ ] `meme`: 元ネタの出典を確認した（誤った元ネタ紹介はこの層に一発で見抜かれる）

### 表示・規約

- [ ] **クレジット表記**がある: `VOICEVOX:ずんだもん` `VOICEVOX:四国めたん`＋立ち絵素材の作者（[08](./08_自動化.md)）
- [ ] TikTokで**AI生成ラベル**を付けた（合成音声を使っている間は必須。[01](./01_市場分析.md) 4章）
- [ ] 説明文に合成音声を使っている旨を書いた
- [ ] 他クリエイターの批評・専門家を貶める煽りが入っていない（[02](./02_競合分析.md) 6章）
- [ ] 会社名・サービス名を出していない（**素材規約上も要許諾**。[08](./08_自動化.md)）

> **事実確認は飛ばさない。** お金の話で数字を間違えると、その1本が滑るだけでなく
> チャンネルの信用ごと飛ぶ。台本はAIが書くが、**確認は人がやる**。

| 補充元 | 拾い方 |

## 8. 主戦場確定後（Phase 2）

判定（[#19](https://github.com/bashaka-sawabe/personal-sns-operation/issues/19)）で勝ちチャンネルが決まったら:

1. 負けチャンネルは**休止**する（削除しない。検索の長尾は残る）
2. 勝ちチャンネルの深掘りテーマを30本作る
3. 台本の型（2章）をそのチャンネルに合わせて調整する（[09](./09_パイプライン.md) の `SYSTEM`）
4. **本人の共演（Phase 2の橋）**の演出を設計する（[04](./04_戦略.md) 7章）
