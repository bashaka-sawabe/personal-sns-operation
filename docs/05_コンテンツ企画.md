> 戦略上の位置づけは [04_戦略.md](./04_戦略.md) 4章。選曲の根拠は [03_トレンド調査.md](./03_トレンド調査.md)。企画は「思いつき」ではなく、02で特定した空白地帯（アーティスト深掘り／データ検証／解説×ショート）に対応させている。

## 0. 制作の型（先に型を決めて反復する）

ニッチ成功事例の共通項は「型を作って反復」（02の3章）。使う型は3つ:

| 型 | 構成（ショート15〜45秒） | 狙う指標 |
|---|---|---|
| ①リフ直撃型 | 0秒=サビ/リフの最高潮 → ワンフレーズ変化 → 冒頭に繋がるループ | 完走率・リピート |
| ②60秒解説型 | 0秒=問い（なぜ◯◯は中毒なのか）→ 弾いて示す → 結論1行 | 保存・シェア |
| ③検証型 | 0秒=結果の数字/意外な絵 → 過程 → 次回予告 | コメント・フォロー転換 |

**工数圧縮ルール**: 撮影は週1回にまとめ撮り（2〜3本分）／1ソース3面書き出し（YT Shorts・TikTok・Reels）／字幕・構成テンプレを使い回す。目安: 週2本で4〜6時間、省力運転は週1本2〜3時間。

## 4. トレンド即応ルール

- [03_トレンド調査.md](./03_トレンド調査.md) の選曲プールを**週次レビューで更新**（THE FIRST TIMES・TikTok Newsroom・Billboardを定点観測）

## 6. 初動30日の流れ（概要）

詳細タスクはGitHub Project（カンバン）で管理。ここでは骨子のみ:

- **Week 1**: 機材・録画環境の確定、アカウント3面開設、A-1収録（ストック2本）
- **Week 2**: A-1＋A-2投稿（初週は「夜の踊り子」セットで参入）、計測開始
- **Week 3**: B-7開始（0→1,000公開）、C-4投稿、週次レビュー1回目
- **Week 4**: A-5投稿、B系1本、初月データまとめ→8月のサカナクション月間計画を確定
