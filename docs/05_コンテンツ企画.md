# 05. コンテンツ企画 — 台本の型と12本のテーマ

> 戦略上の位置づけは [04_戦略.md](./04_戦略.md) 4章。実装は [09_パイプライン.md](./09_パイプライン.md)。
> テーマの一覧は [data/themes.md](../data/themes.md)（ここではなく、そちらが正本）。

## 1. 台本の型 — 5シーン構成

パイプラインが生成する台本は固定の5シーン（[09](./09_パイプライン.md)）。
**型を固定すると、視聴者が「この形式は最後まで見る価値がある」と学習する**（[02](./02_競合分析.md) 4章）。

| # | 役割 | 中身 | 秒数の目安 |
|---|---|---|---|
| 1 | **フック** | 3秒以内に「何の話か」を言い切る。数字か意外性を置く | 3〜5秒 |
| 2 | 本編① | 結論 | 5〜8秒 |
| 3 | 本編② | 理由・仕組み | 5〜8秒 |
| 4 | 本編③ | **一次情報**（「うちの場合は」） | 5〜8秒 |
| 5 | 締め | 一言でまとめる。問いかけを添える | 3〜5秒 |

合計30〜40秒。**尺は音声に合わせる**ので台本の長短をそのまま許容できる。

### シーン4が本体

シーン4に**自分の実例**が入らない台本は、C（アグリゲータ）と同じものになる（[02](./02_競合分析.md) 1章）。
`money` では必ず入れる。`relationship` は「経営者として人を採る／断る」文脈で入れる。

`trivia` には原理的に入らない。**それが `trivia` の構造的な弱点**（[02](./02_競合分析.md) 3章）。

## 2. テーマ選びの基準

1. **検索では出てこない一次情報か、切り口が新しいこと**（横流しは伸びないし、規制される）
2. **15秒で結論まで言い切れること**。言い切れないものは分割する
3. `money` は「実際に会社を回している人しか言えないこと」に寄せる
4. 「〇選」にしない。**1本1論点**

### 良いテーマ / 悪いテーマ

| ○ | ✗ |
|---|---|
| 一人社長の社会保険料のリアルな金額 | 社会保険とは何か |
| 領収書は7年、ではレシートは何年か | 経費精算のコツ5選 |
| 角を立てずに断れる人の最初の一言 | コミュニケーション術まとめ |

左は「知らないかも」と思わせ、30秒で答えが出る。右は調べれば出てくるし、30秒で終わらない。

## 3. 2週間テストの12本

正本は [data/themes.md](../data/themes.md)。ここでは**各テーマの狙い**を書く。

### `money` — 信用移行が最大

| テーマ | 狙い | 一次情報の置き所 |
|---|---|---|
| 経費で落ちるのに9割が申告してないもの | 「損してるかも」で保存させる | 自分が実際に通したもの |
| 領収書は7年、ではレシートは何年か | 誰もが持つ小さな疑問。検索の長尾が効く | 自社の保管方法 |
| 会社にすると税金はいくら変わるのか | 起業検討層に刺さる。Phase 2の本命層 | **法人化前後の自分の実額** |
| 一人社長の社会保険料のリアルな金額 | **最も一次情報らしいテーマ**。7月は算定基礎届の旬（[03](./03_トレンド調査.md) 3章） | 自分の毎月の天引き額 |

### `relationship` — 母数最大

| テーマ | 狙い | 一次情報の置き所 |
|---|---|---|
| 初対面で感じがいい人がやっている3つのこと | 母数が最大。保存されやすい | 商談・採用面談で見ている点 |
| 会話が続かない人がしている質問の形 | 「自分かも」と思わせる | 面談での実感 |
| 角を立てずに断れる人の最初の一言 | 実用性が高い。**経営者は断る回数が多い** | 実際に使っている言い回し |
| 名前を呼ぶだけで印象が変わる理由 | 明日から使える | — |

### `trivia` — 拡散力の上限を測る比較対象

| テーマ | 狙い |
|---|---|
| 日本の会社が4月始まりになった理由 | 会社文脈で `money` と地続き |
| ハンコ文化がなくならない本当の理由 | 共感を呼びやすい |
| お疲れ様はいつから挨拶になったのか | 日常への近さ |
| 名刺を両手で渡すのは日本だけなのか | ビジネスマナー文脈 |

`trivia` は**あえて会社・仕事に寄せてある**。純粋な雑学にすると、勝った場合に
`money` / `relationship` へ接続できないため。

## 4. 投稿の運用

| | |
|---|---|
| 本数 | 12本を2週間で。**4面すべてに同じ12本** |
| YouTube | クォータの都合で**1日6本が上限**。2日に分ける（[09](./09_パイプライン.md)） |
| 公開範囲 | まず**限定公開**。中身を見てから公開に切り替える |
| 投稿直後 | **30〜60分のコメント返信は手動**（[08](./08_自動化.md) 2章） |

## 5. 投稿前チェックリスト（毎回・全項目）

### 内容

- [ ] シーン1が**3秒以内**に「何の話か」を言い切っている
- [ ] 1本1論点になっている
- [ ] シーン4に**一次情報**が入っている（`trivia` を除く）
- [ ] 「〇選」になっていない

### 事実（`money` は特に厳格に）

- [ ] 税率・上限額・要件を**一次ソース**（国税庁・日本年金機構・厚労省）で確認した
- [ ] **「2026年時点」と明示**している
- [ ] 断定していない（条件付きで言っている）
- [ ] 個別の税務相談・法律相談になっていない（**資格の線引き**。[01](./01_市場分析.md) 6章）
- [ ] 自分の実例を**一般化していない**（「うちの場合は」と限定している）

### 表示・規約

- [ ] TikTokで**AI生成ラベル**を付けた（合成音声を使っている間は必須。[01](./01_市場分析.md) 4章）
- [ ] 説明文に合成音声を使っている旨を書いた
- [ ] 他クリエイターの批評・専門家を貶める煽りが入っていない（[02](./02_競合分析.md) 6章）
- [ ] 会社名・サービス名を出していない（Phase 2まで取っておく。[04](./04_戦略.md) 8章）

> **事実確認は飛ばさない。** お金の話で数字を間違えると、その1本が滑るだけでなく
> チャンネルの信用ごと飛ぶ。台本はAIが書くが、**確認は人がやる**。

## 6. テーマの補充

週次レビュー（[06](./06_KPI・運用.md) 4章）で [data/themes.md](../data/themes.md) に追記する。

| 補充元 | 拾い方 |
|---|---|
| YouTube Analytics の検索キーワード | **実際に検索されている言葉**をそのままテーマにする |
| コメント欄の質問 | 「それ知りたい」がそのまま次のテーマ |
| 制度変更 | 変わった制度は**説明のテーマになると同時に、過去動画の点検対象** |
| Threadsの反応 | テキストで先に出して、伸びたものを動画化する（[04](./04_戦略.md) 5章） |

## 7. ジャンル確定後（Phase 2）

判定（[#19](https://github.com/bashaka-sawabe/personal-sns-operation/issues/19)）で勝ちジャンルが決まったら:

1. 負けジャンルのテーマを [data/themes.md](../data/themes.md) から外す
2. 勝ちジャンルの深掘りテーマを30本作る
3. 台本の型（1章）を、そのジャンルに合わせて調整する（[09](./09_パイプライン.md) の `SYSTEM`）
4. 長尺（語り回）の設計に入る（[03](./03_トレンド調査.md) 1章・Shorts→長尺の導線）
