# 09. 動画生成パイプライン

> 最終更新: 2026-07-27 ／ 前提: [08_自動化.md](./08_自動化.md)（自動化の線引き）、[06_KPI・運用.md](./06_KPI・運用.md)（判定指標）

## 1. これは何か

**AI生成映像＋ナレーション**の縦動画を、企画1行から自動で作るパイプライン。
キャラクターは置かず、映像とナレーションだけで構成する。

```
ジャンル × テーマ（1行）
        ↓ Claude API（claude-opus-5 / JSON強制）
台本JSON（フック＋本編3点＋締めの5シーン）
        ↓ ffmpeg
背景画像（グラデーション）＋ナレーション音声（macOS say）
        ↓ ffmpeg（Ken Burns＋字幕焼き込み＋連結）
content/out/<id>.mp4  （1080×1920 / 30fps / H.264+AAC）
```

## 2. 使い方

```bash
# 1本作る
python3 tools/make_video.py --genre money --theme "経費で落とせるもの3選"

# APIキー無しで疎通確認（テンプレ台本＋ローカル素材で最後まで通る）
python3 tools/make_video.py --genre money --theme "テスト" --offline

# 2週間テストの本体。3ジャンルまとめて生成する
python3 tools/make_video.py --batch data/themes.tsv

# 台本だけ先に作り、中身を確認・手直ししてから動画化する
python3 tools/make_video.py --genre money --theme "..." --script-only
python3 tools/make_video.py --from-script content/scripts/money-001.json
```

| 出力 | 内容 | git |
|---|---|---|
| `content/scripts/<id>.json` | 台本。手で直して `--from-script` で作り直せる | 追跡する |
| `content/assets/<id>/` | 背景・音声・シーンmp4（中間物） | 除外 |
| `content/out/<id>.mp4` | 完成した縦動画 | 除外 |

## 3. 前提

| 項目 | 要否 | 備考 |
|---|---|---|
| ffmpeg / ffprobe | **必須** | `brew install ffmpeg` |
| 日本語フォント | **必須** | `/Library/Fonts/ヒラギノ角ゴ StdN W8.otf`（極太でないと小画面で潰れる） |
| `anthropic` SDK | 台本生成時 | `pip3 install anthropic` |
| `ANTHROPIC_API_KEY` | 台本生成時 | 環境変数 or `~/dev/.cowork-secrets/anthropic_key.txt` |
| macOS `say` | 音声生成 | 標準搭載。声は Kyoko |

APIキー・SDKが無い場合は自動でテンプレ台本にフォールバックし、後段の検証だけ先に通せる。

## 4. 設計判断（なぜこうしたか）

### 4-1. 背景に画像生成AIを使っていない

情報系ショートは**字幕が主役**で、背景の要件は「読解を邪魔しないこと」。
テスト期の目的はジャンル判定であって映像美の検証ではないため、
1本あたり数十円と待ち時間を払う理由がない。ffmpegのグラデーションで足りる。

**当たったフォーマットが決まってから**画像・動画生成APIに差し替える。
差し替え口は `tools/pipeline/media.py` の `background()` 一箇所に閉じてある。

### 4-2. 音声を本人の声にしていない（まだ）

同じ理由。テスト期はコストゼロで回す。
ただしTikTokは**AI生成コンテンツのラベル表示が必須**なので、合成音声を使う間は必ず付ける。
ジャンル確定後、本人の声に差し替える（[07_ロードマップ.md](./07_ロードマップ.md) の S3）。
声を本人にすることは「人間が作っている証明」でもあり、量産AI判定の回避にも効く。

### 4-3. シーンごとに独立したmp4を書き出してから連結している

1本のフィルタグラフで全部やると、1シーン失敗しただけで全体が落ち、
どのシーンが原因か分からない。分割しておくと切り分けが効く。

### 4-4. 尺は音声に合わせる

映像を音に合わせることで、台本の長短をそのまま許容できる。
尺の手調整が発生しない＝人の手が入らない＝自動化が壊れない。

### 4-5. バッチは1本落ちても止めない

`--batch` は失敗した本をスキップして残りを作り切り、最後にまとめて報告する。
夜間に流して朝に結果を見る運用を前提にしている。

## 5. 差し替えポイント（当たった後に触る場所）

| やること | 触るファイル |
|---|---|
| 背景を画像/動画生成AIに差し替える | `tools/pipeline/media.py` の `background()` |
| ナレーションを本人の声/高品質TTSにする | `tools/pipeline/media.py` の `narration()` |
| 台本の型（シーン数・構成）を変える | `tools/pipeline/script.py` の `SYSTEM` と `SCRIPT_SCHEMA` |
| 字幕の見た目を変える | `tools/pipeline/render.py` の先頭定数 |
| 配色を変える | `tools/pipeline/media.py` の `PALETTE` |
